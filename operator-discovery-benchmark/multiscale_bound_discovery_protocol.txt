AUTOMATIC STATE AND BOUND DISCOVERY — stage034 capability experiment

Motivation
The earlier detector searched analyst-supplied argument families. A successful
moment allocation did not demonstrate invention of the missing arithmetic
mechanism. This experiment asks a narrower, falsifiable capability question:
can an executable invent auxiliary states AND a globally verified cancellation
bound when no companion state, metric, exponent or successful argument is given?

Search boundary
The generator receives only base b and a callable x(n), n>=0. Starting with
x(n), it enumerates sections x(b^k*n+r), 0<=r<b^k, by closure-driven expansion.
It proposes rational linear recurrence identities from observations. Failed
validation examples change the sample constraints; a failed universal identity
can return a counterexample index, causing structural re-expansion. Complete
state ASTs, rejected relations, queries, limits and proof attempts are saved.
No target answer, recurrence matrix, metric or desired exponent is supplied.
This is finite-dimensional section synthesis, not arbitrary grammar invention.

Global proof boundary
For held-out recursively defined sources, an independent checker receives the
complete source definition and proves/refutes proposed recurrence identities
on the entire reachable linear space. The numerical generator cannot read that
definition. Source base/unit consistency is mandatory; zero extension is not an
unproved recurrence at n=0. Every output state is an actual section of x.

The generator forms A=sum_r M_r and discovers the row space generated by the
target output under A. A checked projection R, starting with the target row,
and reduced matrix L satisfy R*A=L*R. This preserves exact block recovery
without demanding cancellation of auxiliary prefixes invisible to the target.
It tries rational exponents alpha=p/q with
q up to24 (pilot uses0,1/6,1/3,1/2,2/3,5/6,1). It synthesizes a positive definite
Q using finite Gram sums or the rational Stein equation. The checker verifies
(L^q)^t Q L^q <= b^(2p) Q exactly. There are no inferred growth-slope proofs.
The source's row-contractive definition supplies a coefficient bound for every
section; sample values never supply this bound. Full aligned blocks and every
digit remainder recover arbitrary prefixes, not just powers-of-b endpoints.
Finite phase costs, the unit, output projection and all cross terms are paid;
the source cost uses the COMPLETE quadratic form R^t Q R.

Challenge withholding
Source/challenge author knows this grammar, which is a declared limitation.
Actual challenge instances are materialized after producer/checker sources and
protocol are frozen by direct bytes. Search gets anonymous callables. Expected
outcomes and source definitions are not passed to discover(). This is a held-out
implementation capability test, not analyst-blind mathematical novelty.
One-state ablation checks whether synthesized companions materially improve a
bound. Long-transient aliases test that finite fits never become theorems.

Actual arithmetic attempt
The same state learner is applied to the complete archived signed core
 f=(9/2)K*(mu*mu)-(9/2)K*(mu*mu_(2/3))-R_u*K*mu_(2/3)-(9/2)mu,
 K(n)=n^(-1/3), x(n)=f(n+1).
This includes unit, all four modes, all actual primes and their powers, and
all signed crosses on the declared range. It attempts a DIRECT full-core
bound, not a numeric isolation or replacement of the stage033 residual Z033.
The current candidate10_moment_region_obligation.json and its144bindings,
g=f-e, all paid components, opposite drifts and costs remain authoritative and
unchanged. This alternative earns no inherited payment without a separately
verified transfer. Numerical closure on this source is an OPEN arithmetic
lemma: the recursive-source oracle is not available for zeta by assumption.

All archived arithmetic is previously observed development data. No unseen
arithmetic validation or advantage is claimed. Source queries, even exact
finite identities, cannot prove a relation for all indices. A dimension or
depth stop excludes no larger or parameter-dependent arithmetic state family.
If no exact core closure is proved, full-core and RH flags remain false.

Success interpretation
A verified withheld cancellation theorem demonstrates auxiliary-state and
bound synthesis in THIS grammar. It does not establish that finite-dimensional
section closure is suitable for primes or that an RH proof is likely. The
actual arithmetic result must be reported alongside benchmark successes.
