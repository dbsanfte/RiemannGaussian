Objective and exact zero set
Let x=c+Nf be the licensed exact affine chart, D its strictly positive020 dyadic
scale, and f=f018+D*z. Let A_s select all366 square/five slack coordinates,
A_C select C, and A_H select H=P+4C, with full symmetric Frobenius metric.
Write p_i(z)=dist(A_i x(z),K_i)^2/2, where K_s is the nonnegative orthant and
K_C,K_H are PSD cones. In the ideal exact-real model each p_i is nonnegative,
convex and continuously differentiable. Its gradient is
 g_i=(N*D)^T A_i^T[(A_i x)-projection_K_i(A_i x)]/b_i
for normalized r_i=p_i/b_i. Matrix coordinate adjoints require offdiagonal
factor2, and the H contribution to C has factor4.

Freeze b_i=max(exported initial numerical p_i,2^-40), as EXACT positive rational
values reconstructed from the canonical80-digit/dyadic initial records. The
floor is a declared normalization policy, not an estimate of spectral noise or
a mathematical lower bound on a true defect. All three b_i stay fixed for every
trial/iteration. Then F=max(r_s,r_C,r_H) has zero set exactly equal to simultaneous
cone feasibility in the ideal exact model, regardless of which positive b_i are
chosen. Using numerical penalties still requires the independent exact endpoint.
If all initial penalties exceed the floor, initial r_i=1. Any strictly accepted
first decrease forces every block below its own initial penalty. At every later
point, p_i<=b_i F defines a contracting envelope; individual raw penalties may
increase between accepted steps. E.g b=(100,1,1), p=(50,.8,.7) to(55,.7,.6) gives
F .8 ->.7 while the scalar penalty increases. Below-floor blocks can increase
above their initial raw defect within the floor-scaled envelope; no claim that
all raw blocks normalize1 or decrease at every step is justified.

Exact proximal linear model and simplex dual
At current z, r_i and g_i denote normalized values and gradients. For alpha>0,
minimize over d,t:
 t+||d||^2/(2alpha), subject to r_i+g_i*d<=t for i=0,1,2.
Its three-weight dual is
 maximize r*lambda-alpha*||sum_i lambda_i g_i||^2/2,
 lambda_i>=0, sum_i lambda_i=1.
The primal direction is d=-alpha*gbar, gbar=sum lambda_i g_i. Define
 q_i=r_i+g_i*d, t=max_i q_i and nu=sum_i lambda_i q_i.
For ANY simplex lambda, kappa=t-nu>=0 equals the primal-dual model gap:
 [t+||d||^2/(2alpha)]-[r*lambda-alpha||gbar||^2/2]=kappa.
At an exact optimum kappa=0; KKT requires q_i<=nu for every i and equality for
positive weights. These identities give cheap independently checkable finite
export diagnostics without claiming gradient or QP correctness.
In particular,
 t<=F_old-||d||^2/alpha+kappa.
A tiny direction alone should not be described as model stationarity if its
reported/recomputed model gap is large. Exact d=0 with exact KKT is stationarity
of the convex maximum and hence a global minimum; a positive such minimum would
have no feasible zero in that exact finite convex model. Numerical calculations
cannot establish those hypotheses, so NO infeasibility flag follows.
Initial allzero numerical defects may stop explicitly as numerical zero-defect;
the exact endpoint must still be checked before finite admission.

Ideal Armijo derivation and practical limits
If normalized block gradients are L_i-Lipschitz, L=max_i L_i gives
 F(z+d)<=t+(L/2)||d||^2
          <=F_old-(1/alpha-L/2)||d||^2+kappa.
With exact model optimum, the proposed Armijo rule
 F_new<=F_old-||d||^2/(8alpha)
is guaranteed when alpha<=7/(4L). Alpha<=1/L is a simpler conservative bound.
A finite power estimate is not a certified L. Three fixed halving trials need
not reach a safe step: for identical p_i(z)=z^2/2 at z=1, alpha64,32,16 all fail.
Each halved alpha MUST recompute the simplex model and d; merely halving the
previous direction is wrong. For r=(2,1,0), g=(1,-1,0), alpha1 chooses lambda
(.75,.25,0), whereas alpha.5 chooses(1,0,0); both directions are-.5, not scaled
copies. Native PSD gradients/penalties and80-digit model solving remain numerical
proposal data. Exact mathematics above explains the design, not a convergence
certificate for its mixed-precision implementation.

Seven-face solution and degeneracies
All3 vertices,3 edges and1 full simplex face suffice for an exact concave
quadratic in three weights. For edge lambda_i=t,lambda_j=1-t, h=g_i-g_j:
 t=clip_[0,1](((r_i-r_j)/alpha-g_j*h)/||h||^2)
when ||h||^2>0. If h=0, the edge objective is affine in t and a vertex maximizes
it; never divide by zero or invent a preferred mixture.
For full face set u=g_0-g_2,v=g_1-g_2, a=u*u,b=u*v,c=v*v,
 h0=(r_0-r_2)/alpha-u*g_2, h1=(r_1-r_2)/alpha-v*g_2.
If det=ac-b^2>0, solve
 s=(c*h0-b*h1)/det, t=(a*h1-b*h0)/det,
and keep( s,t,1-s-t ) only when all weights are nonnegative. Values outside the
simplex are not legitimate interior candidates and must not be used uncorrected.
If the exact Gram is singular, a nonzero null direction within sumlambda=1 keeps
gbar constant. Along that line the dual objective is affine: any interior optimum
is either improved toward a boundary or is flat and can be moved to a boundary.
Therefore some boundary candidate realizes an exact optimum, including rankzero.

A numerical near-singular threshold is a different statement. The agreed fixed
relative threshold2^-160 can skip the interior as an explicitly numerical-only
fallback; it does NOT prove exact singularity. E.g u=(1,0),v=(1,2^-100) has true
det2^-200>0, below that threshold. A materially negative Gram determinant or
nonfinite data should return UNKNOWN; small rounding-level negative determinants
may trigger the declared boundary fallback. Export determinant/threshold/skipped
status and model gap. Boundary fallback preserves a valid simplex proposal but
may miss the correct model optimum, impair descent or produce numerical stops.
