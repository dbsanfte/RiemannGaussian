Sparse forward and transpose maps

Write the exact affine solution as x=c+N*f, f in Q^445. For each pivot p, the
licensed normalized row is
    x_p = b_p - sum_{j>p} a_pj*x_j.
To compute N*d, set free entries to d and use the same DESCENDING-pivot
back-substitution with zero RHS. To compute N^T*g, initialize a working
1224-vector w=g and visit pivot columns in ASCENDING order. For every row
coefficient a_pj with j>p, update w_j -= a_pj*w_p; then discard w_p. The
remaining free entries are N^T*g. This is reverse differentiation of the
forward solve, requiring one sparse pass and no445-column expansion.
Basis insertion order is not a substitute for pivot-column order.

The same formula works over exact rationals. Exact transpose solves are useful
for calibration/receipt checks, but repeating exact rational arithmetic in
every proposal iteration is unnecessary and risks coefficient-bit growth.
Use finite floating versions of the EXACTLY licensed sparse coefficients for
proposal generation, record their conversion, and reject overflow/underflow.
Use exact maps for final reconstruction. Additional native triangular equality
constraints would reintroduce equality residuals while keeping more variables;
they offer no exactness advantage over direct free-coordinate evaluation.

Concrete differentiable convex merit

Let S extract the366 square and five slack coordinates. Define negative parts
componentwise for scalars and spectrally for symmetric matrices:
    F(f) = (1/2)*||min(S*x,0)||_2^2
         + (1/2)*||C_-||_F^2 + (1/2)*||H_-||_F^2,
    x=c+N*f, H=P+4C.
Squared distance to a closed convex cone is convex and differentiable, including
at repeated/zero eigenvalues. Thus this is a convex penalty; its zero set is
exactly the desired quotient cone on the affine system. F>0 at a finite iterate
or stalled descent never proves infeasibility. The exact forced auxiliary slack
can remain in S or be eliminated under its existing proof; no empirical face
truncation is allowed.

The coordinate gradient before the transpose solve is:
    scalar gradient = min(S*x,0);
    C matrix gradient = C_- + 4*H_-;
    P matrix gradient = H_-;
    signed-relation direct gradient =0.
For upper-triangle matrix coordinates, use the diagonal gradient unchanged
and DOUBLE every offdiagonal matrix-gradient entry. This factor is essential
because the merit uses the full symmetric Frobenius norm. Then g_f=N^T*g_x.
Compute negative parts with two15x15 eigendecompositions for numerical
proposals only. Final PSD decisions use exact rational LDL with zero-pivot
handling and full reconstruction, never floating eigenvalue clipping.

sqrt(2) offdiagonal weighting. This bounds the merit curvature when evaluated

    N*d=(-2*d0,d0,d1,d1).
