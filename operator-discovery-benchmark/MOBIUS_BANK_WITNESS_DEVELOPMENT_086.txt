The model is the existing complete anchored Boolean geometry, ordered as
anchor followed by every squarefree composite. The root-owned typed bank
provides complete exact integer columns through integer_column. The frozen
full projected remainder is reconstructed by mixed.original_remainder.
Only anchor1 and the bank's known arithmetic geometry enter witness search.

For a bank numerator column c, a composite binary variable xi=(si+1)/2 obeys
sum(i>0) ci xi=(sum(i>0)ci-c0)/2. Denominators cancel from this homogeneous
constraint. Exact parity, gcd divisibility, zero-row and binary interval
checks precede numerical optimization and provide literal receipts if an
integer contradiction is detected. A genuinely justified arithmetic bank
has the actual anchored Mobius vector as a feasible witness, so a claimed
contradiction for such a bank is an implementation inconsistency requiring
audit. Absence of an elementary contradiction proves no feasibility.

Numerical integer rows are gcd-reduced and all row absolute sums plus rhs
are bounded below2^50 before lossless double conversion. Fixed MILP objectives
maximize gradients R*s from all-plus, top and bottom eigen-sign starts and a
seeded random start; further requested attempts use predeclared seeded random
starts. The floating remainder is rescaled before eigen/gradient proposals to
avoid overflow. Default search has four calls, each at most ten seconds and
1000 requested branch nodes. HiGHS receives threads=1 explicitly. SciPy's
warning that this option is passed through verbatim is captured per call.
Numerical work requires OPENBLAS_NUM_THREADS=1 and OMP_NUM_THREADS=1 before
process launch; other native thread environment entries must be unset or1.

The branch-node cap may decrease under the model's cumulative charged-work
budget. The common cap and prospective per-node work estimate are recorded.
Dimension E<=512, bank size<=16, integer coefficient/denominator bits<=4096,
cumulative exact rational bits, dense memory, exact quadratic work, and the
full eigen-start work all receive prospective gates. Charged work is a
conservative resource estimate rather than an exact executed-instruction
count. The inherited memory budget remains4GiB per worker.

Each numerical proposal is rounded to literal binary signs, then checked
against every complete exact integer bank column and anchor1. Numerical
feasibility tolerances and tiny residuals never admit a witness. Compatible
vectors receive the full exact rational quadratic evaluation s^T R s and
certificate keys squarefree_count, signs, lower_bound. Optional improving
flips change zero constraint columns or identical-column opposite-sign pairs;
the anchor is never flipped. Exact compatibility is rechecked after each move.
The already admitted vector survives local-search failures. All candidates,
start receipts, solver statuses, warnings, local moves and failures are kept.
The best lower bound is retained even if negative. When no compatible vector
is admitted, certificate=None and status NO_EXACT_COMPATIBLE_WITNESS_FOUND
assert no bound. HiGHS numerical infeasibility is explicitly unproved.

The default successful status is EXACT_COMPATIBLE_BANK_WITNESS_PROPOSAL.
An exact elementary obstruction instead yields EXACT_BOOLEAN_BANK_INFEASIBLE
with literal proof details, for audit rather than scientific interpretation
when the bank is a theorem-backed arithmetic bank. No global quadratic
maximum, actual signed-drift lower bound, all-scale obstruction or RH result
is inferred from these finite artificial witnesses.
