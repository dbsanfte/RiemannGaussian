An exact simplification of the anchored-storage certificate cone

This is an algebraic resource optimization, not a new signed arithmetic bound.
It applies to the complete, unnormalized full14 state with the SAME matrices
shared at every t and X. It does not justify dropping arithmetic source terms.

Write A_G(X)=sum_(X<=t<2X) V_t^T G V_t. The matrix part of the current RHS is

  A_Gp(X) + A_Gc(2X) + A_K(2X) - 4 A_K(X),

with Gp, Gc, K PSD. Define

  K' = K + Gc,
  Gp' = Gp + 4 Gc,
  Gc' = 0.

All three new matrices are PSD, and substitution gives exactly the same RHS:

  A_Gp'(X) + A_K'(2X) - 4 A_K'(X)
  = A_Gp(X) + A_Gc(2X) + A_K(2X) - 4 A_K(X).

The converse inclusion is immediate by setting Gc=0. Therefore the certificate
cone generated by the three matrices is exactly the cone generated by Gp and
K alone. This is true as a formal polynomial identity for arbitrary complete
vectors, at every scale, including X=1. No observed Möbius signs or candidate
weights enter the argument.

The coerced state becomes R'=e_P e_P^T+K'. It still dominates prefix energy.
Its initial value increases by v_1^T Gc v_1, which is finite and must be
retained. The target rearrangement remains exact: the increase in the storage
increment is balanced by the changed proof terms. This is not an inference
that a larger positive energy inherits an innovation bound automatically.

All formal constants also agree. With z=(0,0,0,0,0,-1/2,...,-1/2), the old
matrix constant is

  X z^T Gp z + 2X z^T Gc z - 2X z^T K z.

The reduced constant X z^T(Gp+4Gc)z - 2X z^T(K+Gc)z is identical. No cross
constant, unit boundary or scalar-budget term has been omitted.

On the dual side H_K=H_child-4 H_parent, so H_child=H_K+4 H_parent.
Positivity of H_parent and H_K already implies positivity of H_child. Thus
the entire child PSD condition is redundant in the anchored cone. The same
fact holds for the restricted diagonal-moment proposal when the necessary
offdiagonal equations are retained or transformed exactly.

A future numerical parameterization can therefore remove Gc and retain all
105 entries of Gp and all 105 entries of K, with an exact map back to the
original three-matrix schema. It must preserve the full monomial domain,
shared scalar coefficients, source geometry, target, gamma gate scope, initial
cost and independent full-cone admission. This changes numerical conditioning
and cost, not the set of provable inequalities. The current frozen search
and saved-support leaf replay keep their declared parameterizations intact.
