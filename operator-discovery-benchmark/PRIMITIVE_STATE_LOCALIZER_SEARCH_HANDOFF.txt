Complete arithmetic expansion

For each integer t, R_f(t) sums every primitive relation in the canonical
domain of family f. All seven existing families are included: unit, norm,
prime_power, squarefree_zero, inverse_row, coprime_product and gcd_product.
The source domains and all witnesses are specified in
primitive_state_localizers_uniform_scope.txt. Actual primality and exact
factor witnesses certify these sources; no table of Mobius signs or fitted
signed responses is supplied to the grammar.

Let U(t) be the unchanged full15 affine state, including the constant,
prefix, half, even, mod3one, prime and all nine divisor contrasts. For each
family, parent/child region and every coordinate i=0,...,14, add

  L_(f,r,i)(X) = sum_(t in r(X)) U_i(t) R_f(t).

These are 210 signed relation groups with fixed shared coefficients. Every
primitive vanishes at x_n=mu(n), so every new relation vanishes for EVERY
integer scale. Repeated primitive specs are aggregated distributively by
adding their multipliers; complete pre-aggregation coverage remains in the
archives. Empty groups retain their descriptor positions. The gamma-zero
auxiliary appends 210 empty groups, with zero added gamma coefficients.

All 366 old square groups, 403 old relation groups, the three full15 matrix
blocks and the original target are retained. The new relation count is
613. This is a grouped subspace of the arithmetic ideal, not the complete
ideal. A coefficient cannot vary with the individual primitive, t or X.

The producer constructs suffix multipliers; the independent checker

The producer can omit a redundant expanded-polynomial metadata hash after

Scalar scope and recovery

The formal state constant vector is z=(1,0^5,(-1/2)^9). The seven aggregate
relation constants are -1, -SF(t), pi(t), 0, 0, 0, 0. Therefore the formal
constant of L_(f,r,i) is z_i times the corresponding regional sum. This
formal coefficient is distinct from the actual initial arithmetic state.

There is an explicit elementary quadratic bound for fixed signed weights
beta. Set u_r=sum_i |beta_(unit,r,i) z_i| and
n_r=sum_i (|beta_(norm,r,i) z_i|+|beta_(prime_power,r,i) z_i|).
Using SF(t)<=t and pi(t)<=t gives, for integer X>=1,

  |B_beta(X)| <= X u_parent + 2X u_child
       + (3X^2-X)/2 n_parent + (6X^2-X) n_child
    <= (u_parent+2u_child+3n_parent/2+6n_child) X^2.

No prime-distribution estimate is used in this budget. For fixed
coefficients it is compatible with an X^(2+1/q) critical allowance, but
does not establish the nonconstant polynomial identity or signed bound.
The new quadratic term cannot cancel the old cubic gamma term under the
previous fixed-template scalar-growth hypotheses. Gamma-zero remains a
conditional necessary gate, not a theorem about all possible RH proofs.

Storage remains a signed child-minus-four-parent increment. With PSD K,
R=e_prefix e_prefix^T+K, so S_R dominates the prefix energy. Initial cost
is still 1+u^T K u for the actual t=1 state u. A successful proof still
requires a uniform identity and innovation budget at all needed scales,
the appropriate cofinal q family and the previously recorded energy/Mellin
bridge conditions. Finite tests cannot discharge those quantifiers.
