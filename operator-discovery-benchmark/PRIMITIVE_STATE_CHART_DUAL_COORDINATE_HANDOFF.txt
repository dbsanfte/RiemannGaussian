Next research action
Do not restart032 or extend its trajectory after seeing the result. Sparse
updates provide substantially more explicit proposal steps than the old
dense per-pivot reservation, but this first coordinate schedule has not
approached an exact representation. Repeating the same method with only a
larger memory or wall-time limit would not address its numerical behavior.

A new experiment should test a faster sparse method for the same feasibility
residual, with its initialization, step policy, work limits and support rule
declared before execution. A useful candidate is accelerated projected
gradient with a dimension/sparsity-metered line search, followed by the same
single exact support solve. It should report the unpenalized residual and
stationarity diagnostics, so a slow trajectory can be distinguished from a
numerically stationary positive residual without treating either as proof.
Support selection must not silently discard small positive weights; a
separate declared support-reduction method would need explicit accounting.

The851 fixed generators are only a portion of the PSD dual cone. Failure to
find a separator here leaves additional rank-one directions open. Dynamic
ray generation from primal/dual residual information is another substantive
method change, not grounds for a claim about every operator grammar. An
exact separator, if eventually found, would exclude this augmented finite
proof template; it would not supply the desired signed arithmetic estimate.
The ultimate task still requires a valid operator identity, uniform scalar
and initial-storage bounds, a cofinal parameter family and a bridge to
ordinary zeta. These remain unresolved.
