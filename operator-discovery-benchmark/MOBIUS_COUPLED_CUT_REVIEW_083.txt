Scope and disposition

The Boolean trace price is valid on the full physical squarefree coordinates;
it genuinely strengthens082's independent group-box price. The old082 dual
cannot be transferred merely by deleting its clamp. Coupled cut profiles also

unit-balanced cuts n and N-n removes the quadratic-price outer block jointly,
including all actual prime/composite pairs. The remaining full signed cross
kernel is unpaid. No original source bound or RH conclusion follows.
No frozen082 file is changed, and no old science/tests or raw source values
are queried. This is a mathematical review for the proposed083 grammar.

1. Boolean price and exact dual

Every retained physical coordinate is squarefree, including unit, so actual
mu(n)^2=1. For symmetric A, actual mu^T A mu<=B(A), where
B(A)=trace(A)+2sum_(m<n)|A_mn|. Diagonal entries may be negative. This is a
correct finite upper price, not an entrywise/PSD upper bound for arbitrary
vectors of norm<=1. An implementation which groups coordinates and substitutes
a group mean must restore within-group Boolean variance exactly; old082
aggregate groups cannot use this trace formula unchanged.

Incidence zero additions have actual quadratic form0; positive Gram additions
have actual quadratic form>=0. Thus A=A0+sumthetaZ+sumpositiveGram satisfies
actual original drift<=actual mu^T A mu<=B(A). A negative finite B is allowed;
it simply bounds a potentially negative drift. It is not a negative energy.

For arbitrary rational |nu_mn|<=2, L(A)=trace(A)+sum_(m<n)nu_mn A_mn<=B(A).
Minimizing L independently over theta in[-16,16] and Gramweights[0,16] gives
LB=L(A0)-16sum|L(Z)|+16sum min(0,L(vv^T)). The diagonal coefficient is fixed1,
not a variablelambda. Ordered/unordered factors2 must be checked exactly.
Feasible LP dual rounding uses exact clipping to[-2,2]. This lower bound
concerns this certificate price cone, not actual arithmetic drift or a
counterexample to the desired bound.

Split the complete corrected target exactly as outerblock+crossblock+inner

 D_n(m)+D_(N-n)(m)=(1-e_n)/(N-1)*floor(N/m)-R_N(n,m).

6. Conservative obstruction diagnostics which remain useful

A PSD formal covariance M=zz^T+diag(1-z_n^2), |z_n|<=1, hasdiag1 and supplies
Boolean dualnu_mn=2z_mz_n. Unlike082's covariance, its diagonal correction
must be included. L(A)=z^TAz+sum_n(1-z_n^2)A_nn. For coupledzero templates,
L(Z) need not vanish, even if aggregate fixed floor moments vanish. This is
exactly how the coupled language can escape the old witness. Never import
an082 rank witness as a083 obstruction without recomputing these functionals.

For rawcuts whoseK(n)<=floor(u/5) on allouter coordinates, choosez=1 onouter
and0 elsewhere. Their outeroffZ iszero; L(Z)=traceZ. Its absolute price is
bounded by W*Kmax*(1+ceil(log2N)) for boundedweightW. Source diagonal costs
onlyO(u), so fixed coefficient boxes leave an orderu^2 price obstruction
when these trace/penalty terms are lower order. For balanced globally
sublinearcuts, the subtractedC_N term has coefficientO(Kmax/N), hence the
additional outer functional costs at mostO(u*Kmax); stilllower order if
Kmax=o(u). Full/linear coupledcuts, complements nearN and prime/composite
filters need separate analysis; no generic impossibility is assumed here.

Actualprime/composite filters preserve physical coordinates and signed target
cross terms; they are arithmetic descriptors, not additional proof that a
formal sign equalsmu. If a dual countermodel is required to fix actualprime
signs, add those affine/covariance constraints explicitly. Simply labeling
weights prime does not impose them. Conversely actual primal arithmetic
identities remain valid for filteredgeometry weights without any sign fit.

The new Booleanprice and unit-balanced coupledcut grammar are mathematically
legitimate. The matchedn/complement motif pays an actual all-scale wholeouter
