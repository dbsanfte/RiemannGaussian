Numerical algorithm
Minimize f(x)=half||A*x-b||^2 with x>=0 and no penalty. Start x=y=0,t=1.
Set L0=max_j(math.hypot(*column_j)^2), finite positive, and require finite
nonzero target norm. This is a starting step estimate, not an asserted
global Lipschitz constant. Fresh sparse products use math.fsum per row or
column; temporary product buckets require nnz+m cells. Guard all intermediate
products, sums, norms, squares, ratios, candidate coordinates and momentum
against nonfinite values BEFORE projection or other clipping.

Before starting a step, require remaining allowance>=iteration_reserve+final.
If this fails at an accepted boundary, stop normally with work_boundary.
If max_operations<minimum_attempt, do no setup/iterations and return an
incomplete unattempted proposal. Reserve the final diagnostic at every guard.
Before each block charge its whole declared proxy, including partial work
on error. Additional deadline/live checks use charge(0), no hidden cell+1.

One gradient block computes fresh r_y=A*y-b and g=A^T*r_y. Up to32 trial
blocks: z=max(0,y-g/L),d=z-y; compute fresh A*d and r_z=A*z-b separately.
Accept iff ||A*d||^2<=L*||d||^2, with finite checks including RHS product.
Otherwise double L and retry at same y and gradient. Carry the accepted L
to the next step. A32-trial rejection, nonfinite result, deadline or resource
failure interrupts the trajectory: completeFalse, selectedNone.

One commit block computes accepted residual/support, then
  tnew=(1+sqrt(1+4*t*t))/2
  ynew=z+((t-1)/tnew)*(z-x).
Every64th accepted iteration instead resets ynew=z,tnew=1. x=z is always
nonnegative; momentum y is unrestricted. Compute all accepted state and
metrics before appending the checkpoint, so a partial commit cannot be
misreported complete. Increment iteration after a complete commit.
After each accepted checkpoint, stop if its reported residual norm is zero
(zero_reported_residual), or if iteration=10000(iteration_limit); otherwise
continue to the next boundary guard. No tolerance/convergence stop is used.

Each accepted checkpoint stores iteration(1-based),backtracking_trials,
lipschitz,residual_norm,relative_residual,support_size,momentum_restarted,
cumulative_operations (after its commit, before final). Keep at most10000.
Select min(relative_residual,support_size,iteration) over1..443 positive
coordinates, saving the FULL vector and every strictlypositive index.
No coefficient threshold or support trimming is permitted.

On normal termination compute one charged final diagnostic at the LAST
accepted x: fresh r, g=A^T*r, projected p=max(0,x-g/L), norm=L*||x-p||.
Store iteration,lipschitz,residual_norm,relative_residual,projected_gradient_norm.
It need not describe the selected earlier checkpoint. It is only a floating
stationarity diagnostic. Only after it succeeds is complete=True. None of
the line tests, stopping rules, zero norms or stationarity values is a proof.
