## 1. Exact congruence twist and carry

For a public unit colour j modulo k, use its inverse modulo H=k² and the true canonical phase lambda_j(a,b). The integral shear

    T_s(a,b)=(a+k*s*b,b)

has determinant one and is the identity modulo k. It therefore preserves EVERY stationary lattice Lambda_j. Define

    c_s=floor((lambda-k*s*b*j)/H),
    lambda_s=lambda-k*s*b*j-H*c_s in [0,H).

Then this is exactly the selected phase of the transformed row, and

    E_s-E=k*s*b*(1-j)-H*c_s.                       (1)

For actual P=j mod k, put T=(P-j)/k. Stationary indices satisfy

    I_s-I=s*b*T-c_s.                              (2)

Thus this lawful mutation preserves stationary coverage before checking bounds, and has fully acquired canonical carry. Its geometric action is the standard integral slope shear underlying torus Dehn twists; the native arithmetic identities (1),(2) are derived directly, not asserted by a skein theorem. Frohman–Gelca's [torus skein product-to-sum source](https://arxiv.org/abs/math/9806107) supplies the familiar slope setting, not a scalar interval-selector theorem.

All transformed coefficients, phases, and labels have O(log N) bits for bounded s. If the transformed vector leaves the supplied low-product catalogue, it cannot be counted as an old query leaf. The next section avoids this problem entirely.

## 2. Actual admitted two-row pairs for every colour

For each unit j mod k choose

    a=[N*j^-2]_k in {1,...,k-1}, b=1,
    v=(a,1), T_(-1)v=(a-k,1).

Both rows satisfy the SAME colour condition and have 0<|ab|<k. Their selected lambda phases are actual native roots. Here

    c=floor((lambda+k*j)/H) in {0,1},

Consequently the true colour has an actual SAME-FIELD shifted edge between two public nodes at shift h_*=-T-c. Unlike the old mixed-prime swap promise, this mutation really does force a same-field overlap, precisely the kind the new shifted-gcd certificate can use.

For j!=1 the integer gap for ANY supplied h is

These nodes may be included as AUXILIARY fixed-shift inputs even when a previous special-row query pruned them: this does not restore a deleted physical leaf. ## 3. Why the forced edge is not a small supplied shift

The row dependence in (2) is compressed to the publicly acquired shared ratio

    R_j=beta^[k*(1-j)],
    R_j=q^T mod P, T=(P-j)/k.                      (5)

Indeed the exponent difference is k*(P-1). Since P<=sqrt(N)<=k³, 0<T<=k². Equation (3) forces a shift of absolute size T or T+1. A short-shift list of radius B catches this particular edge only when T+c<=B.

There is no hidden wraparound rescue in the relevant small window: if k²+B+1<16H, then |(-T-c)-h|<ord_P(q) for |h|<=B. Equality of the two mutated nodes at that prime therefore forces h=-T-c as an INTEGER. The actual physical B=O(k^(3/2)) horizon, with its inherited explicit constant, satisfies this guard. In particular for P>k*(B+1) this actual correct-colour mutation pair has NO edge in the tested short-shift window. Wrong-colour coincidences might still factor; no theorem forces one. This is a precise failure of the proposed universal short-shift implication, not a special-prime numerical counterexample or an assertion that all adaptive mutations fail.

## 4. Complete coverage of all forced shifts: exact cost

One can make (5) into a guaranteed algorithm by querying every unit j!=1 and T from1 through ceil(sqrt(N)/k). This covers the smaller factor's actual quotient and returns a factor by (4), with the certificate's saturation handling. Treating the acquired R_j as a root list and applying the old joint geometric evaluator gives soft O(k+sqrt(k*sqrt(N)/k))=soft O(N^(1/4)), in the worst balanced scale. It is worse than the current native soft k^(5/4) query.

The underlying exponent family explains this completion exactly. Put B0=beta^k. Then

    R_j-q^T = B0^(1-j)*(1-B0^(k*T+j-1)).           (6)

Thus all colour/quotient tests flatten to the ordinary exponent n-1 with n=k*T+j running through unit residue classes below a bound of order sqrt(N). This has O(sqrt(N)) factors. For a numerical upper bound one may instead include every 1<n<=ceil(sqrt(N)) coprime to6; all original candidates P are retained, and every extra exponent k*(n-1) is nonzero and has O(log N) bits. The two residue classes modulo6 give a constant number of scalar q-Pochhammer products, acquired in soft O(N^(1/4)); proper/saturated localization uses the same inherited consumers. The n=1 global zero is excluded explicitly.

Including n=1 mod k with n>1 is also harmless here: its quotient T<k²+1 is shorter than ord(q), so its q^T-1 factors are units. Unit status suffices for predicates; no numerical correction product is mandatory. No smooth-order or distributional assumption is used, and primorial/logarithmic refinements are old baseline rather than a new power gain.

Injective N-powering of (5) merely multiplies its unknown quotient T by N modulo the local order. It does not supply a smaller acquired representative. ## 5. Scope and next genuine possibility

This is a positive universal SAME-FIELD overlap construction with a fully paid complete fallback. It does not solve the desired problem because its forced shift range is O(k²), and the completed cover is the classical factor-size/order cover (6).
