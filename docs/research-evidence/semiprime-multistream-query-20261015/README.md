## New arithmetic obstruction

[Polynomial top bands](reports/polynomial-top-bands-obstruction.md) permit B prescribed nonconstant monic polynomials F_b(N), shared across candidates m, and ANY adaptive top shifts |s|<=C_s m^2 and selected prefix indices k<=C_k m^2. All bases must retain the supplied gamma's local prime orders. For BD_*<=M^.010, deleting only O(BD_* M^5.969)<=O(M^5.979) inputs leaves the same-order-qualified majority family on which EVERY permitted stream value is a unit, simultaneously at every candidate. Products, unit ratios, integer powers and unit prefactors therefore cannot represent the actual proper-factor rows, however many of these streams are used.

The key is that every possible collision forces F_b(Q)=t modulo the intrinsic R_P>P^.677, with t=r-s in ONE interval of O(M^2) integers. The monic polynomial root bound counts all choices at once; no extra candidate, shift or index factor is charged. This includes the actual delta_j offsets. The library must be fixed as N varies; arbitrary input-selected polynomial coefficients are outside the theorem.

Two independent reviews passed: [review A](reviews/polynomial-tops-review-a.md), [review B](reviews/polynomial-tops-review-b.md). This is a rigorous obstruction to the stated rowwise multiplicative route. Additive cancellation, arbitrary m-dependent tops, a different observable, norm-only acquisition and factor-only algorithms remain open. The proof does not exclude a fast scalar query merely because these representations fail.
