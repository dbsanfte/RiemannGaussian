FRESH PRIMARY 2026 SOURCE
Pantelimon Stanica, Erik Mulder, Markus Hittmeir:
Multi-target hyperbolic sieves and elliptic trace obstructions.
arXiv:2606.13018v2, revised 5 October 2026.
https://arxiv.org/abs/2606.13018
https://arxiv.org/html/2606.13018v2

The paper gives actual finite-field candidate-set constructors:
  H_a(N;l)={a*x+N/x : x in F_l^*},
  |H_a|=(l+chi(a*N))/2.
For an explicit coefficient family A, Proposition 6.1 constructs the union
in O(|A|*l) field operations, after O(l) inverse precomputation. Thus this
is paid data acquisition and a guaranteed menu for the LINEAR FORMS
  a*P+Q mod l,
not for P mod l. Unions of k coefficient sets have size
  l*(1-2^(-k)) + error,
with explicit error at most (k-1+2^(-k))*sqrt(l)+k. CRT products cover k^t
coefficient classes using one product menu over t auxiliary primes.

For primitive-root coefficients (g,g^2), the exact union cardinality is
controlled by one elliptic curve trace t_g. Proposition 6.2 / Remark 6.3
allows deterministic Schoof point counting in poly(log l) per explicitly
supplied primitive root. This computes the SIZE and tests a local bound;
it does not determine the actual factor sum P+Q mod l. Membership in the
image can itself be tested by chi(z^2-4*a*N) != -1.

The paper explicitly states in Introduction and Conclusion that it proves
no improvement of deterministic factorization: construction costs AND
subsequent search would need analysis. The restricted r-th-power images
apply to a known input shape N=u^r*v, not a general distinct semiprime.
The source therefore does not currently close this task. Its exact
multi-target menu remains a possible ingredient if another task supplies
a cheap shared linear-form consumer; no such consumer was supplied here.
