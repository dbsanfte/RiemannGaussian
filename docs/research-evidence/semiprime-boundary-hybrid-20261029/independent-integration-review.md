## Findings requiring integration care

Its header correctly describes the unchanged mixed report. `HybridPublicExecution.work` is a distinct executed program with boundary partition acquisition, validation and contraction. Corrective action: use the changed program's own additive `treeWork`, prove its local allowance, then include every search query and factor/cofactor decoding cost. The new public numerical correctness join does not itself discharge this resource obligation.

2. **All-fuel call bounds do not imply scheduled stopped-leaf bounds for arbitrary fuel.** `HybridCallTree.eventually_count_le` and `HybridCallOriginal.eventually_original_count` correctly quantify over every fuel, via the existing finite call-count cap. However, the new recursion deliberately executes a boundary leaf at fuel zero, even if the node is still active. Such a node need not satisfy the stopped-leaf size premise of `PartitionOriginalRate.eventually_acquired_width_half`. Corrective action: the improved half-scale leaf exponent must use sufficient scheduled fuel, or explicitly prove the size premise at the stopping node. Keep arbitrary-fuel numerical correctness and arbitrary-fuel call counting distinct from the stronger scheduled work-rate statement.

3. **The fixed-power polynomial wrapper was not present in the frozen files.** `LeafPolynomial.run_clock_polynomial` has a closed explicit `closedBudget ctx V M`, and the reviewed definition contains fixed additions/products/powers in graph size and current context dimensions. It is a genuine metadata-only expression, with no hidden table count or runtime oracle. The snapshot does not yet include a theorem of the form `closedBudget <= C * (inventory+1)^k` with uniform constants. Corrective action: review that forthcoming wrapper separately before claiming that exact uniform-power endpoint. Likewise, the reviewed rate theorem is uniform over valid graphs with explicit size and maximum-degree premises; its eventual network/reachable-call specialization must discharge those premises.

These are scope and integration gates, not discovered false arithmetic lemmas. No mathematical defect was found in the reviewed closed variance/width statements or the reviewed explicit native leaf-report inequalities.

## Arithmetic and partition checks

- The runtime potential has the correct common `K^4` scale: pair expectations use scale four, single expectations use scale two, and the mean numerator is multiplied by the latter. Completing all endpoint colours gives `(K^2 * load - meanNumerator)^2`. The ordered edge-pair list includes diagonal and repeated parallel occurrences.
- `ConditionalAverage` handles an endpoint absent from the local factor and an endpoint at an arbitrary position in its first-occurrence catalogue. Its final averaging and descent theorems are proved from the actual enumerator; closed `acquired_width` has no supplied averaging, good-partition or mean premise.
- `Overlap` counts literal occurrences, and bounds ordered touching pairs by `2*M*Delta`. Disjoint covariance vanishes; the quarter-scale upper bound is an upper bound on each covariance, not an assumption of nonnegative covariance. Summing yields initial potential at most `K^4*(2*K-1)*M*Delta/2`.
- The exact consecutive merge mean is `2*M*(j*(K+1-j)-1)` for actual `2 <= j <= K`. `MergeMean.mean_identity` discharges all bucket and merge means used by the variance endpoint.
- The width argument divides by positive `K^2`, bounds every measured load rather than an average load, and correctly propagates through the maximum fold. Its closed correction is `sqrt((2*K-1)*M*Delta/2)`.
- The first-success cube search is bounded, and on a valid nonempty graph has positive degree and a passing last candidate. The preceding candidate failure supplies the upper cube-root comparison. The resulting width bound `M/2 + 3*(M^2*Delta)^(1/3)` has explicit validity and nonempty-graph premises. Empty graphs remain covered by direct finite runtime behavior; the nonempty asymptotic theorem does not silently include them.
- The original-scale half-width theorem has an explicit epsilon and explicit degree/size hypotheses, with an eventual threshold independent of the graph. Its reserve constant 864 follows from `m <= L+1 <= 2L` and cubing the correction target. It is not a bound for arbitrary large active nodes.
