## Exact Frobenius complement

For coprime a,m>1 let G be the positive gaps of the semigroup generated by a,m. Set g=(a-1)(m-1)/2, F=am-a-m=2g-1 and S(z)=product_(r in G)(z+r).

For 0<=r<=F, exactly one of r and F-r is a gap. A direct proof: write r=mi-aj with 0<=i<a. If r is a gap, j>=1, and

    F-r=m(a-1-i)+a(j-1)

is representable. Both cannot be representable because F itself is a gap: reducing an alleged representation of F modulo a forces its m-coefficient to be at least a-1, which already exceeds F. This proves the complement assertion without invoking numerical observations. Consequently

    S(z) S(-z-F)=(-1)^g B_(2g)(z),
    B_d(z)=product_(r=0)^(d-1)(z+r).

This is a polynomial identity over the integers. It uses no product inversion. For a=1, S=1 and g=0; that empty case contributes no support and must not be used as a covered query.

## Native reflection realizes exactly the needed arguments

Opposite labels j and m-j have the same a and satisfy

    b_(m-j)+b_j-2a=m tau,  tau in {-2,-1,0},
    c_(m-j)=-c_j+ma+m^2 tau.

Let z_j(K)=c_j/m+mK modulo N, using only the certified inverse of m. Then

    z_j(K)+z_(m-j)(K')=a+m(tau+K+K').

Thus choose the public reflection

    R(K)=C-K,  C=1-a-tau.

The paired arguments sum to -F exactly, so their acquired gap product is one ordinary factorial B_d(z_j(K)), d=2g, with the known sign (-1)^g.

Let I0=[-m-2,m+2] be the complete old menu of block starts. For each unordered opposite-tag pair choose one representative j. Put I=I0 union R(I0). Since |C|<=m for m>=5 and I0 has length 2m+5, this is one integer interval [Klo,Khi], is R-invariant, contains I0, and has O(m) points. The product of the gap norms of both rows for all K in I equals

    (-1)^(g |I|) product_(K in I) B_d(c_j/m+mK).

This is the exact acquired target contraction. Original gap family support is retained, but this alone would not import the original rectangle's hit coverage; the independent coverage proof below is necessary.

## Independent all-input coverage

The native residue map is

    c_j=-N/j modulo m.

It is a permutation of all nonzero residues, and opposite tags have opposite residues. Thus representative tags for the unordered opposite pairs represent every nonzero residue up to sign exactly once.

    t=(n-c_j)/m is integral and |t|<m^2+3m/2,

More strongly, the same argument works for EVERY integer 1<=n<=m^3 with m not dividing n: exactly one of n,-n lies in a representative low residue. ## Initialized aggregate cost

There are (m-1)/2 representative rows. Each merged h_j is O(m^2); since I contains I0 its length is also at least 2m^2+O(m) for every a>=2. The total explicitly specified progression length is Theta(m^3), even though the list of progression endpoints is only O(m).

The following computes their aggregate without enumerating those leaves. Normalize each progression factor c_j+mt=m(c_j/m+t). Set B near m^(3/2). Build the common B_B(X). For each row split its h_j factors into length-B blocks and a tail. Generate its h_j/B block starts (total O(m^3/B)); acquire all block values by one monic MPE and multiply. Decompose each tail into binary lengths, build B_(2^k) up to B, and acquire all requested tail values by one MPE per k. Summed tail degrees O(B), targets soft O(m). Include the known scale m^(sum h_j) by powering. All starting arguments, endpoints and exponents are acquired O(log N)-bit metadata.

The complete ring-operation bound is

    soft(B+m^3/B+m)=soft m^1.5.

No factor values, target lists, or large polynomial coefficients are free. This is an initialized upper bound for the displayed algorithm, not a lower bound for other scalar algorithms. The a=1 exceptional rows fit soft m and do not change the bound. Binary restriction of public rows and then index intervals recomputes these same products; it gives proper-factor localization within the same soft m^1.5 clock, up to logarithms.

    (-1)^nu product_(A<n<=W, m does not divide n) n,
