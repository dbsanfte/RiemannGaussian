# Uniform product acquisition would remove the orientation dependency

24 October 2026. This is an exact conditional transfer contract, not an
acquired fast product algorithm or a new factoring exponent. It identifies
which stronger recurrence interface would complete the original guaranteed
query without requiring the later QRH orientation palette.

Use the already acquired FULL canonical parity-repaired row family, retaining
both colours, original row/index metadata and all seed guards. Its size is
J=O(k), horizon L=3k²+2, and k has sixth-root scale. The existing arithmetic
coverage theorem guarantees a local hit for the smaller factor, without
assuming that this factor is the nonsplit prime. Keep the original
saturation/annihilator consumer and the paid small-factor, scalar and torus
preparation. Relevant exact sources are native-pairing.md
`06548c974c61d9922a4ec6c2f41ba1c95d7dfcbb92442b3b2e5ceff984cd8016`,
rough-torus-working.md

This report does not claim a newly completed Lean implementation of those
cost contracts.

Suppose an algorithm, given the actual monic polynomial

    F_S(X)=prod_(j in S)(X-V_j),

the actual q and L, returns a verified proper factor OR the EXACT scalar

    E_S=prod_(0<=i<L) F_S(q^i)

in soft(|S|+sqrt L) bit work at the prepared logarithmic coefficient sizes.
It must support the full family and the subfamilies selected by a balanced
binary partition. It may not assume that there is only one local hit.
Root differences need not be inverted by this interface. Any separation
preparation a proposed implementation uses must itself be paid or return
a factor, and must preserve original labels.

Here is the complete query consumer for that contract. Acquire the
subfamily polynomial tree in soft J. Query the full set S. Up to the unit
sign (-1)^(|S|L), E_S is the original product over the actual row/grid
differences. Its norm is therefore nonunit by the original coverage
theorem. A proper gcd returns a factor. If its gcd is N, retain S as a
saturated node and query ONE child S_left. A proper gcd again factors;
a saturated child can be selected directly. If the child's norm is a
unit, select S_right: E_S=E_left E_right and norm multiplicativity prove
that its norm is saturated without querying it. Thus only one child is
queried per level, and the saturated invariant is preserved. No equality
at a split coordinate is mistaken for whole-algebra equality.

At a singleton, use the established original length-L row locator and
its original index/leaf recovery. Its soft sqrt L cost is already paid
by that source; an auxiliary derivative or matrix value is never passed
off as an original collision witness. The sum over the selected path is

    soft(sum_d J/2^d + sqrt L * log(J+1))
      =soft(J+sqrt L)=soft k.

All polynomials, queries, norm gcds and localization work are included.
This proves a whole-family acquisition transfer, not merely a one-row or
one-orientation claim. Combined with the existing prepared-controller
contracts it is the desired mathematical acquisition bottleneck; an
actual algorithm satisfying the hypothesis and the full executable/Lean
bit-cost composition are still missing.

There is a corresponding exact-gradient contract. If a routine returns
the actual pair (T0,T1) of gradient-product.md for every such F_S AND
its monic one-step shift q^(-|S|)F_S(qX), through EVERY zero pattern,
then that report's two-call identity supplies E_S at the same soft cost.
It divides only by q^L-1, whose unit guard is already acquired. It does
not require either boundary F_S(1),F_S(q^L) to be a unit. The required
monic scaling, coefficient construction and q powers are paid softly
linearly in |S|. This stronger exact-output interface is distinct from
a routine returning only a valid ratio or bounded failure on an
unrecognized unique-hit label.

Consequently a uniform soft-k product/gradient algorithm of this kind
would not need QRH-based orientation selection for coverage: the original
full family and its existing unconditional coverage supply the hit.
This is a CONDITIONAL ALGORITHMIC IMPLICATION, not an unconditional
sixth-root algorithm already obtained. A native unique-hit-only shortcut
still has the separately documented orientation promise and its explicit
analytic condition. The two possible research routes must not be conflated.

The current actually executed product/gradient routine costs
soft(|S|+sqrt(|S|L)); the same descent therefore remains soft k^(3/2).
Nothing in this transfer removes that cost or substitutes an oracle for
its missing implementation. Its role is to keep the all-semiprime scope
and the exact useful interface explicit while a faster recurrence is sought.
