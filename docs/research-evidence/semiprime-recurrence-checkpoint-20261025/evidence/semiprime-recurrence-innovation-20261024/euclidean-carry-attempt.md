# Euclidean Sylvester-gap carry norm: initialized recurrence and charged evaluation

2026-10-24. Scratch only; no repository changes or examples. This derives and executes a Euclidean carry-product recurrence. It gives a denominator-safe soft sqrt(am) one-row computation, hence at most soft m, but its literal whole-row-family implementation costs soft m^2. It does not improve the old sufficient factorial-cover query, which costs soft m^1.5, or attain the required soft m whole query.

## Exact carry set

Write M=m temporarily and fix 1<=a<M with gcd(a,M)=1. The rectangle consists of a h+M k, 0<=h<M, 0<=k<a. Its carry residues are

    C(a,M)={a h-M l : 1<=h<M, 1<=l<=floor(a h/M)}.

Indeed, at fixed h>0 the carried k are a-floor(ah/M),...,a-1, and putting l=a-k gives the formula. Every displayed residue is positive and below aM. The count is (a-1)(M-1)/2. This is exactly the set of positive gaps of the numerical semigroup generated by a,M, not an arbitrary subset.

For completeness, the alternative gap parametrization is

    C(a,M)={M i-a j : 1<=i<a, 1<=j<=floor(M i/a)}.

Proof of the gap claim: reduce any positive gap n modulo a to obtain the unique i in [1,a-1] with n=Mi-aj. If j<=0 then n is representable; if j>0 but n=au+Mv with u,v>=0, reducing modulo a forces v=i+at with t>=0 and hence n>=Mi, a contradiction. This also proves uniqueness and symmetry of the two parametrizations.

Define the monic gap polynomial

    S(a,M;z)=product_(n in C(a,M))(z+n).

The empty base S(1,M;z)=1 is explicit. Nothing treats S as supplied coefficients.

## A genuine Euclidean recurrence

Let M=q a+b, 0<b<a. Splitting j at qi in the alternative parametrization gives the exact polynomial identity

    S(a,M;z)=S(b,a;z) * T(a,q,b;z),
    T=product_(i=1)^(a-1) product_(j=1)^(q i)(z+M i-a j)
     =product_(i=1)^(a-1) product_(t=0)^(q i-1)(z+b i+a t).

The second factor of the split has j=qi+t and equals z+bi-at; these are precisely the gaps of (b,a). This recurrence uses only integer Euclidean metadata. It performs no inverse of a product value. Both forms of T are needed: the first proves the disjoint gap partition, the second initializes common-step factorial evaluation.

A small Euclidean remainder does NOT make T short. In particular M=a+1 terminates after this stage, but T still has a(a-1)/2 factors. Naming this object a weighted factorial, double gamma, or Barnes G does not acquire its modular value. The initialized evaluation below charges it explicitly.

## Actual triangular-product evaluator

All arithmetic is modulo N, or any fixed power N^e if requested; a is a certified unit. For each i=1,...,a-1 initialize

    x_i=z/a+(b/a)i,   L_i=qi.

Then T=a^D product_i B_(L_i)(x_i), D=q a(a-1)/2 and B_l(X)=product_(t=0)^(l-1)(X+t). The exponent D has O(log N) bits on the native scale; its power is acquired by binary powering.

Choose an integer B near a sqrt(q), bounded between 1 and max_i L_i (unless there are no rows). Build B_B(X) by a balanced product tree. Write L_i=B f_i+r_i. Generate all explicit full-block starts x_i+Bv, 0<=v<f_i, and evaluate B_B at their union by monic MPE. The total number is at most D/B. Multiply the acquired values.

For the short tails, build B_(2^k) for 2^k<=B. Decompose r_i in binary. Starting at x_i+Bf_i, a set bit k contributes one acquired B_(2^k) value at the current start, then advances that start by 2^k. At each k perform one monic MPE on its actual at-most-(a-1) starts. The sum of polynomial degrees is O(B); the summed target count is O(a log B). Thus these nonuniform tails cost soft(B+a), including all starts and tail metadata. No inverses of node differences or evaluated factors occur.

The complete initialized triangular computation therefore costs

    soft(B + D/B + a) = soft(a sqrt(q))

ring operations, with the usual residue-bit factor. The Euclidean stages sum to soft sqrt(aM): the first a sqrt(q)<=sqrt(aM), and the subsequent costs are bounded by a constant times a, since Euclidean successive large entries halve every two stages and u sqrt(floor(v/u))<=v. The same construction computes S at a supplied z directly, without constructing its degree-Theta(aM) polynomial.

This is an actual acquired scalar, but its bound matches ordinary baby/giant scale. It is not a new sub-square-root-in-the-number-of-gaps theorem.

## Denominator-safe correction and localization

For c'=c+M^2 K0 put z=c'/M in Z/N (M is a certified unit). If g=(a-1)(M-1)/2, the two carry products are

    denominator = M^g S(a,M;z),
    numerator   = M^g S(a,M;z+aM).

Acquire both scalars by the algorithm above. If the denominator is a unit, invert it and use their ratio to correct the ordinary degree-aM factorial. If its gcd is proper, return that factor instead. If its gcd is N, localize its acquired product; do not invert it.

Localization is initialized: split the Euclidean factors S(b,a) and T; within a triangle split the public i interval, recomputing the same variable-length evaluator restricted to that interval. At a single i use ordinary additive-factorial interval halves. This finds a nonunit leaf in logarithmically many calls, each bounded by the full one-row cost. Native correction leaves are nonzero modulo m and have absolute value <N for K0 in the supplied menu, so a nonunit leaf has a proper gcd. The same applies to the numerator if that branch is useful. The product may saturate; gcd=N is never itself called a factor.

For arbitrary c' without the native envelope, this still computes the norm lawfully, but literal zero or N-multiple leaves would require separate handling; no unconditional factor-recovery claim is made in that larger domain.

## Whole-family ledger and stopping point

The native a_j=N j^-2 mod m are O(m) acquired metadata. Each value of a_j occurs at most twice, so a positive fraction of the m-1 rows have a_j>=m/4. Applying the displayed evaluator independently generates a_j-1 starts in its first triangular stage whenever a_j>1. Consequently this literal all-row implementation materializes Theta(m^2) starts (already before full blocks and tails), and its total upper bound is soft sum_j sqrt(a_j m)=soft m^2. This is an operation count for this initialized implementation, not a lower bound on implicit norms or a different Euclidean algorithm.

Normalization makes the baby factorials common across rows, so their construction can be shared. It does not remove the Theta(m^2) acquired i-targets in this implementation. A further compression of precisely these triangular targets, with modular values and nonunit handling initialized, would be new work; a recurrence for their metadata alone does not provide it.

The period a_j differs with j. Computing just the K-block [K0,K0+a_j) in every row also does not by itself cover the complete [-m-2,m+2] menu. Additional blocks and final tails must be charged in any covered algorithm. No coverage reduction is inferred from the Sylvester-gap identity.

The constructive output of this attempt is the exact Euclidean gap recurrence and its explicit soft sqrt(am) scalar acquisition/localization. No faster whole-query exponent is obtained; no generic impossibility statement is claimed.
