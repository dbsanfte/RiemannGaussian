# Explicit short-atom wide-annihilator lemma and the missing bridge

24 October 2026. Compact checked reusable lemma. This generalizes the already used prime-factored kernel closure to gcd-free COMPOSITE leaves by an old coprime-base algorithm plus the existing short-annihilator consumer. It is not acquisition progress for the current long collision query.

Assume N=P Q, k=Theta(N^(1/6)), N<=k^6, H=k^2, and a supplied unit beta whose two local orders are odd, coprime and>16H. Inputs are an EXPLICIT list of nonzero integers d_t, each with O(log N) bits, total input width L=soft k, and the proved promise beta^K=1 globally for K=prod_t d_t. Remove signs and ones; zero atoms are NOT permitted. No prime factorization of any d_t is input.

Primary: Daniel J. Bernstein, *Factoring into coprimes in essentially linear time*, Journal of Algorithms54(2005),1–30, author manuscript https://cr.yp.to/lineartime/dcba-20040404.pdf . Cached sources/bernstein-coprimes-2004.pdf SHA256 `49a78cd05264e3c0c544ef40d36b593218c422b2c02f8547ad8b6f44d71a0e46`. Algorithm18.1/Theorem18.2 gives an explicit M-time bound for the natural coprime base; Section8 defines its arithmetic cost model. Substituting fast integer multiplication/exact division/gcd gives input width times polynomial logarithms. This soft bound uses that explicit theorem, not an inference that an arbitrary n^(1+o(1)) bound is polylogarithmic overhead.

1. Compute a coprime base g_1,...,g_w>1 for the absolute atoms. Each g_j divides an input atom and every input factors over them. Remove unused generators, so sum_j log g_j<=sum_t log|d_t|. The cost and stored basis are soft L.

2. Put e=ceil(log2 N), A_j=g_j^e and K'=prod_j A_j. The A_j are pairwise coprime. Each local beta order is<N and all its prime factors occur in the atom product. Every prime valuation in such an order is at most e, so it divides K'. Therefore beta^K'=1 globally. Each A_j has O(log²N) bits; the ENTIRE width T=sum_j bitlength(A_j) is soft L. Build its actual product tree in soft T. This caps valuations without factoring a g_j.

3. A complementary exponent tree acquires u_j=beta^(K'/A_j) in soft T total work. At a node representing a subtree product D, keep u=beta^(K'/D); for children products D1,D2 compute u_left=u^D2 and u_right=u^D1. Sibling exponents at a depth have total bitlength O(T), so binary powering over all depths costs soft T including actual modular arithmetic. This is the previously credited Celler–Leedham-Green/Sutherland complementary-tree technique, not a new generic order algorithm.

4. Scan gcd(u_j-1,N). A proper gcd factors. If all values were1 globally, the beta order would divide the gcd of all K'/A_j, namely1 (the one-leaf case has complement1 too). That contradicts its supplied orders. Thus absent a factor there is a j with gcd(u_j-1,N)=1. Its two local orders are nontrivial, odd and still coprime.

5. Run ONE existing factor-or-exact-common-order screen for this u_j through16H, cost soft k. An exact common order would be1 by coprimality, contradicting the selected unit difference. Hence this screen factors or certifies BOTH local orders>16H. Meanwhile u_j^A_j=beta^K'=1 globally, and A_j is a positive nonzero O(log²N)-bit annihilator. Invoke the existing unbalanced short-annihilator extractor once. Its exact promises are met, and its cost soft N^(31/192) is within soft k. There is no inversion, hidden local order or factoring of A_j.
