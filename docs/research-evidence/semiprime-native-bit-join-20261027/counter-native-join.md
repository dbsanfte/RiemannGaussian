# Actual source-to-controller connection

The new public path is `SemiprimeNativeBitsScheduledController.run N` → `SemiprimeNativeBitsPublicController.factor/search/prefixRun/counter` → `SemiprimeNativeBitsSetupCounter.count` → `SemiprimeNativeBitsCounter.count` → `SemiprimeNativeBitsCounter.group` → `SemiprimeNativeGroupBits.run`. The last function executes `NativeLocalBits.nativeLocal`, which actually calls corrected-port word Horner/mask/addition and the physical Boolean local tree, followed by physical truncated group multiplication. This is an executed caller replacement, not just a sufficient backend theorem.

The original source producer runs once per count query. `SourceWordAcquisition.acquire` encodes its retained coefficient arrays once, paying the original source report, scalar digit extraction, original-incidence index scans and finite cache construction. `NativeBitsCounter.acquireInputs` then executes every exported row getter once and stores the whole report. `inputWork_acquire` proves the exact sum of those retained getter costs. Every interpolation node is encoded once before the node traversal. No coefficient, encoded source, shifted row, group value, rank, count, or intermediate Fits answer is a public input.

`PrefixEntryWords.entry` calls the original Boolean checker and every-occurrence prefix gate once. The accepted bit is placed directly in a one-cell signed word. This preserves the actual original arithmetic/equality-vertex checker and avoids an unnecessary integer/rational encoding boundary at each leaf. The prefix gate and finite addressing still have their stated finite-control ledger scope.

The physical corrected-port proof uses the original source common denominator throughout Horner and column sums. Every dot-product prefix and addition is justified from the same original representation. The local proof propagates these bounds through both branches; the group proof extends them to the actual gated factor list and its product suffixes. Total incidence affects the chosen width polynomially. Boolean enumeration remains `2^(arity e)` for each original factor; no `2^(sum arity)` traversal is introduced.

`MaterializedGroupAdapter` preserves the existing head acquisition, representative search, summary, support and Hermite loops. It retains each new group Run rather than equating its work with the old group. `NativeBitsCounter.count_correct`, the actual setup theorem, and the public scheduled theorem prove correctness of the new execution path. Equality of outputs does not transfer the old clock theorem.

`NativeGroupBitsBudget` bounds the actual physical local/product report. `NativeBitsCounterBudget.count_work` instantiates that result and discharges the group-cost premise of the traversal theorem. Original word lengths, dimensions, entry clocks and acquired design sizes remain explicit. The original-source setup bound derives the source lengths and physical width from actual construction data. The same support/head/summary factors remain.

The `toScalarRun` boundary really decodes physical words to rationals for the outer interpreter. Its declared normalization/copy allowance is retained and bounded by actual output sizes. This allowance is not a proof about the host rational implementation or a literal tape machine. Similarly, source score computation and canonical numerator/denominator extraction are still scalar, not silently reclassified as physical source production.

The earlier `FullReportRate.run_report_subpower`/`run_report_sixth` results remain frozen and valid for the earlier full-setup controller's retained mixed report. This packet does not identify the new report with that one. The explicit new group/width bounds use fixed polynomials and the same large enumeration factors, but the new public uniform report-rate composition and the complete primitive-bit/address refinement must still be proved.
