## Full local arithmetic check

Fix an actual admissible P,m and width-m^2 half-open Q box. For EACH fixed tag j and prescribed i, the residual-zero equation is Q+delta_j-m^2i=kR. The offset bound has width 4m^2 and the Q box has width at most m^2. Therefore the total interval has length at most 5m^2<R, so there is at most one possible integer k. This remains true for arbitrarily large signed indices. It is important that a different tag can have a different k; the proof correctly applies this argument separately per tag/index and never grants a single common k across row-dependent indices.

Multiplying the equation modulo m by P and substituting PQ=a j^2 gives

a(j^2-2Pj+P)=P k R modulo m.

The signs and the constant P term are correct.

For A_j nonzero, this fixes at most one canonical slope a, and hence fixes Q modulo m. At a false tag j!=P modulo m, the coefficient 1-P I_j is a unit modulo m^2. For two possible Q partners, the literal lift difference then gives (1-P I_j)(Q-Q')=0 modulo m^2, so Q=Q' modulo m^2. A half-open width-m^2 box contains at most one such Q. Thus fewer than m nonexceptional false tags and B_* indices per tag contribute O(m B_*) states.

A_j is a monic quadratic in j, so at most two tags are exceptional. At each such tag and each index, one can safely retain all m-1 possible slopes. The own tag cannot be one of them: A_P=P(1-P) is nonzero modulo m because the retained supply has P and P-1 units modulo m. Each exceptional tag is therefore false, and fixed-slope uniqueness applies. Total exceptional contribution is at most 2(m-1)B_*.

At the own tag, A_P is nonzero, so one slope and one Q class modulo m are still fixed for each index. The false-tag unit coefficient is unavailable here, and the proof correctly does not use it. A width-m^2 box has O(m) integers in that class, giving O(m B_*) own-tag contribution. No assumption that the sampled index is outside the true-index range is needed. This is why the catalog extension is stronger than just transporting the endpoint-band argument.

All three cases together give O(m B_*) bad integer Q states in one box, uniformly in the actual R and the index locations. The counting argument is valid for each actual prime P, and the O(X) number of possible P is merely a cardinal upper bound; it does not assign an order to arbitrary composite integer P.
