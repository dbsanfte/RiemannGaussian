# Next executed-bit handoff: intrinsic Hermite reconstruction

Read-only plan; no sources changed. The smallest substantive next slice is a word-valued replacement for `AcquiredHermite.node` and `reconstruct`, consuming the actual completed-node JetReports directly. Preserve ascending t=0,...,Q−1, invoke each node callback once, copy exactly J words, retain its entire clock, and accumulate the reconstructed scalar as a RationalReport. Prove its word value equals the CURRENT `AcquiredHermite.reconstruct` value on decoded packets. This removes the per-completed-node rational decode and scalar Hermite arithmetic from the executed path; it does not close source/metadata/addressing or final integer-floor execution.

## Literal reusable construction

For node t, implement the existing `HermiteArrayHeight.hermiteNode` exactly: acquire `cardinalSlopes Q J t` (QJ entries, including explicit zero at s=t); multiply the affine factors to obtain L; independently evaluate the same factors at x=−(t+1) for cardinalZero; compute the cached inverse of L; multiply the acquired H by that inverse; evaluate the J-coefficient quotient at x; multiply by cardinalZero. Cache L/inverse/H and all reports; do not recompute node callbacks or recursive prefixes.

Use `JetBits.multiplyBits` / `WordFold.mul` for the finite affine products and quotient multiply, `DotBits.dotBits` for each next inverse coefficient and scalar evaluation, and `RationalBits.executeOperation` for scalar add/mul/neg. The cached inverse is exactly `JetArray.buildInverse`: start with b0=1 and append b_n=−sum_{i=0}^{n−1} L_{i+1} b_{n−1−i}. `cardinalJet_constant` proves L0=1, so this inverse requires NO reciprocal oracle or possibly-zero pivot. The only nontrivial reciprocal inputs are the acquired integer differences t−s at s≠t; construct their signed words explicitly and use `rawInvBits` followed by reduction/fit. Their nonzero proof follows from the distinct finite indices, not runtime advice. The s=t branch is literal zero, never inverse of zero. Scalar final sums can reuse `WordFold.sumFrom` with J=1 (or a scalar counterpart with the same chronological recursion).

## Height strategy already largely proved

Do not use a generic rational circuit-height recurrence. Let dC=`cardinalDenominator Q J`. Existing `cardinalSlopes_representation`, `cardinalJet_intrinsic_representation`, `cardinalJet_suffix_representation`, `cardinalZero_suffix_representation` cover intrinsic factor data and recursive products. `buildAffine_dotPrefix_representation` covers inner convolution accumulators. `inverse_dotPrefix_representation` covers EVERY partial normalized-inverse dot sum with denominator dC^J; `cached_inverse_common_representation` and `quotient_dotPrefix_representation` cover cached inverse coefficients and quotient convolution prefixes. `evalPrefix_power_representation` / the quotient evaluation bounds cover scalar evaluation. Use these operation-by-operation to derive `Fits`, then invoke `executeOperation_correct`; do not assume Fits for intermediate values.

The actual word node theorem already supplies a common input denominator DG^r and numerator Cq*Y*productBase^(2r). DG and r are common across actual nodes; choose uniform maxima of the public node numerator bounds (or an acquired sum bound). `hermiteDenominator Q J dH` is one denominator shared by ALL reconstructed node outputs. `hermiteNode_representation`, `hermite_prefix_representation`, `hermite_prefix_dyadic`, `hermite_prefix_bit_lengths`, and `hermite_bits_polynomial` therefore prevent denominator growth by the number Q of accumulated outputs. The explicit `cardinalBits`, `inverseBits`, `hermiteDenominatorBits`, `hermiteNumeratorBits` supply a polynomial-width frontend from the original packet-height exponent. Choose a strict larger public template including the above temporary-prefix bounds; final-output bounds alone do not justify all primitive Fits.
