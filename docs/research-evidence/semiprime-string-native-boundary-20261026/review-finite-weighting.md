# Independent review: finite-weighting.md

26 October 2026. Paper review only; no tests or repository edits.

Verdict: the finite deformation, componentwise decoder and explicit over-budget execution are correct, with the minor unnecessary size inference identified below now corrected in the source. The reciprocal gcd is an OLD acquisition target concretely represented here, not newly acquired at the target rate.

1. At a hit y_j=x_i, the factor is delta(1-Y x_i) exactly. At a nonhit its delta-constant is a nonzero field scalar. The first local polynomial coefficient is consequently A_p times the full product over hit leaves, with nonzero constant-in-Y A_p. This prevents spurious cancellation of the first slice. Row/clock separation makes the degree the number of distinct shared roots; thus Y^d gcd(F,G_clock)(1/Y) has exactly the stated normalization.

2. The first nonzero a_d modulo N either has a proper gcd (unequal local orders) or is a unit (equal local orders). An a_d with gcd N is simply still zero and is not a stopping coefficient. After unit normalization, the full slice has the correct reciprocal gcd at BOTH components. No local-uniqueness or common-index promise is required.

3. Exact integer root deduplication must retain source labels. The inherited derivative/alias guard handles any remaining numerical collision with the proper-gcd or licensed nonzero exponent route, costing soft(J+T_ext), not soft J factor-return in general. This is explicitly charged. At most one terminating extractor is paid. On continuation row differences are units at both primes. Multipoint evaluation at y_j^{-1} uses monic point divisors and needs no further inverses of node differences. A saturated value means that this row hits each component, possibly at DIFFERENT clock indices; the one-row clock query then supplies a genuine original nonliteral leaf. The soft(J+d+sqrt h+T_ext) consumer is valid.

4. Resolved correction (source updated after this review): section 1 says p>16H and J=soft O(k) imply that all integers through J are units. Soft-O alone does not give this finite inequality. It is unnecessary for this Hasse-coefficient and monic-evaluation construction, so delete the inference. If integers through the hit degree are needed elsewhere, use d=s_p<=h and the original clock separation, which gives h<=ord_p(q)<p. No factorial normalization is needed for the displayed Hasse slice.

5. The triangular jet has monomials delta^a Y^b, 0<=b<=a<=d, hence Theta(d^2) coefficients. The degree-J leading coefficient in the clock variable is a unit in this jet ring, since its delta-constant is a product of acquired units. Thus the stated lifted monic backend is initialized, but its rank multiplier leaves the old query cost even for fixed d. Precision doubling and first finding order at Y=0 do not remove this scalar acquisition. Exact termination for zero-hit subfamilies still requires sufficient precision or the ordinary unit-product test; no cheaper zero-order oracle is implied.

6. The affine-clock law z_(i+1)=q^-1 z_i+(1-q^-1)delta Y is correct. Expanding psi(xy)/(psi(x)psi(y)) gives 1+delta[1+Y(xy-x-y)]+O(delta^2), as written. This defeats reuse of ONLY the previous two multiplicative generators in this normalization; it does not exclude expanded or projective state closures. Finite qq sums retain actual endpoints and deleted-term corrections. No source theorem in the report supplies the missing finite arithmetic state weighting.

The report accurately preserves native sectors, carries and consumer scope. No new full-query rate or first-slice acquisition is established.
