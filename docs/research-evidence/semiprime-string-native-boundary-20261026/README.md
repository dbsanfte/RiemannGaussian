# String proposal on the native coloured support

26 October 2026. **No improvement in the complete query exponent.** This
continuation executes the proposal's main native-support cancellation and
finite-weighting directions. The preceding packet specialized the proposal
to a different, independently covered universal rectangle. The full
all-semiprime deterministic classical sixth-exponent goal remains open,
including acquisition, recovery, bit complexity and eventual Lean proof.

The useful distinction is now precise: the inexpensive boundary loses
interior collision information, whereas an explicit deformation retains
that information and admits a paid decoder, but its acquisition remains
expensive. These are different requirements. We have not proved a handoff
that satisfies both within the target budget. In particular the deformation
recovers the OLD reciprocal gcd target; it is not an independently acquired
invariant that can simply be joined to the boundary.

## An arithmetic requirement that a small boundary must meet

The [coverage report](boundary-coverage.md) proves that every NONAXIS row in
the old signed catalogue obeys

    |aP+bQ+lambda| >= Q-kP-H.

If Q-kP>H(M+1), none has its stationary certificate in the original
[-M,M] window. Q>=25kP is sufficient under the prepared size bounds.
The old uniform coverage proof must therefore use axes in this regime.
This does not exclude useful accidental modular hits, and does not prove
that a particular preparation controller necessarily continues there.

There are actual semiprime families compatible with the size and odd-order
promises in that regime, with P/H tending to infinity. Fix 0<gamma<1/2
and take primes 11 mod12 in

    P in (64 k^(2+gamma),128 k^(2+gamma)),
    Q in (k^(4-gamma)/32768,k^(4-gamma)/16384).

The cited explicit prime-progression theorem supplies these intervals for
sufficiently large k. Then k is the actual native least scale above N^(1/6),
and Q/(kP) tends to infinity. Thus a fixed constant-times-H trial prefix
does not remove this coverage obligation.

Axes are not just four scalar phase rows. The full catalogue has k phases
per horizontal sign. Their safe completed query tiles a geometric interval;
the existing engine costs soft sqrt(kM), or soft sqrt(P) with the supplied
adaptive horizon in the above family. These are upper costs of that method,
not lower bounds. Restoring nonliteral leaves from a deleted full-catalogue
row only adds certified units. Completing the smaller unit-tag family to
all phases is instead a safe overcover, not equality of its scalar/predicate.
A new small covered family must handle this distinction and the axis regime.

## A concrete collision-retaining state

The [finite-weighting report](finite-weighting.md) replaces each original
normalized leaf, with clock point x_i and row root y_j, by

    f_(j,i)(delta,Y)=1-(1-delta)y_j/x_i-delta Y y_j.

At a local hit it is exactly delta(1-Y x_i). After the inherited paid
row-separation guard, let s_p be the local number of hits. Then

    [delta^s_p] product f_(j,i)
      = A_p product_(hits)(1-Y x_i),  A_p != 0,

and all lower delta slices vanish. The constant-Y coefficient cannot
cancel. Different first local orders give a proper gcd. Equal orders allow
unit normalization to the reciprocal monic gcd of the row and clock
polynomials. Multipoint evaluation at the acquired inverse row roots
identifies a hit row. A saturated value requires only one original
length-h row query, followed if necessary by the once-only extractor.
This consumer is soft O(k), including arbitrary hit multiplicity, without
a unique-hit or common-clock-index promise.

This proves a recovery interface; it does not acquire the slice. A fully
initialized product recurrence over its triangular Hasse jet costs

    soft O((d+1)^2 (J+sqrt(Jh))), d<=J.

Even fixed d leaves the old query scale. No new factoring code or numerical
campaign is warranted by this overbudget execution.

The attempted boundary handoff is exact and exposes the additional state.
Retaining the row character changes the clock to
z_i=(1-delta)/x_i+delta Y, with affine update
z_(i+1)=q^-1 z_i+(1-q^-1)delta Y. Retaining a multiplicative clock instead
changes the row root to psi(y)=(1-delta)y/(1-delta Yy), which is not a
multiplicative colour character. Its first mixed jet already contains
1+Y(xy-x-y). The old two-generator recurrence consequently cannot be
reused unchanged. This does not rule out an expanded or projective state.

## Decision and proof status

if they supplied new bulk information. The constructive target is a paid
closure that acquires the collision-retaining first slice (or a sufficient
original-row statistic) while handling the affine clock, actual carries
and finite endpoints. Alternatively a smaller family needs a genuinely new
coverage theorem, including axes. Neither implication is proved here.
