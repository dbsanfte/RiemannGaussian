## 2. An explicit divisor-retaining finite weight

For formal delta,Y, replace each normalized original leaf by

    f_(j,i)(delta,Y)
       =1-(1-delta)*y_j/x_i-delta*Y*y_j.            (1)

At a true local hit y_j=x_i this is EXACTLY delta*(1-Y*x_i). At every nonhit its constant term is a nonzero field element. Form the finite product

    P(delta,Y)=product_(j,i) f_(j,i)(delta,Y).

Then at each local prime its first nonzero delta coefficient is

    [delta^s_p]P=A_p*product_(hit leaves)(1-Y*x_i),
    A_p=product_(nonhit leaves)(1-y_j/x_i)!=0.      (2)

All lower delta coefficients vanish as POLYNOMIALS in Y. Formula(2) retains multiplicity, the actual clock positions and every cancelled collision factor. Its constant coefficient in Y is A_p, so it cannot disappear by cancellation of a finite-field weighted sum. This is a finite algebraic weighting with actual initial state1, not an arbitrary additive observable assigned a beta decoder.

The undeformed P(0,Y) is exactly the old normalized product. This is an alternative finite expression for the earlier gcd/subresultant acquisition target, not new scalar acquisition and not a proved computational separation from the full product.

## 3. Complete decoder from the first nonzero slice

## 5. Execute native character and clock compatibility

On a colour lattice the true unwrapped scalar is the supplied character ytilde(v), with y(v)=q^-tau(v)*ytilde(v). Formula(1) uses the ACTUAL y(v); its source integer labels and clocks are unchanged at delta=0. At nonzero formal deformation it can be written in two exact ways.

Keeping the original characters, the row factor is1-y(v)*z_i with

    z_i=(1-delta)/x_i+delta*Y.

Thus every finite Young/colour boundary identity remains an identity at its supplied argument z_i, with the known per-row q^-tau(v) inserted. However z_i is AFFINE-geometric, not the original multiplicative clock. In particular z_(i+1)=q^-1 z_i+(1-q^-1)delta Y. A qq screening calculation must carry this new finite endpoint/weight data rather than assuming the old shift pairing.

Alternatively normalize each row factor using the formal unit1-delta Y*y:

    f_(j,i)=(1-delta Y*y_j)
          *[1-x_i^-1*psi(y_j)],
    psi(y)=(1-delta)*y/(1-delta Y*y).              (6)

The removed prefactors have constant1, so they do not change the FIRST nonzero delta slice (2); no numerical nonunit is divided. But psi is not a multiplicative colour character. For unwrapped x=ytilde(v),y=ytilde(w), direct expansion gives

    psi(x*y)/(psi(x)*psi(y))
      =1+delta*[1+Y*(x*y-x-y)]+O(delta²).          (7)

Canonical q-carries must be inserted separately; they do not set the Y-dependent mixed coefficient to zero. Uniform external rephasing can absorb a constant centre term, but not generally the varying x*y-x-y term. Thus the attempt to normalize the weighted leaves and reuse ONLY the old two-generator character recurrence fails at its first mixed jet. The new coefficient is acquired for a supplied pair, but a scalar closure across all support/clock pairs is not supplied by that fact.

Equation(7) is a test of this specific normalization, not a statement that no nonlinear/projective character or expanded finite state can handle it. Keeping z_i instead preserves the row character algebra, but leaves exactly the affine-clock finite product whose initialized cost was paid in(5). These are the two concrete forms of the same attempted handoff.
