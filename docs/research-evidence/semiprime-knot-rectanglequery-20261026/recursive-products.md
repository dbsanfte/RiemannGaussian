## 1. Difference collapse is prior/concurrent input here

The parent and qhol's exact reduction replaces rectangle pair edges by nonaxis differences w=(a,b), |a|<A,0<|b|<B, in Lambda_j, with clock n=0,...,W, W=6k+1. The lambda-difference carry is0 or−1, so the original short edge maps to n=s−c in this interval. The guaranteed edge cannot have b=0 because equal-b stationary indices differ by more than P/k−1>6k. Also a=0 is impossible with |b|<B<=k and lattice membership. Consequently every augmented original/transposed leaf has its own public nonzero short beta label. This removes the need to reconstruct an original pair or to retain the old cell filter for that supersuperset. I checked these steps against qhol's report rather than presenting them as a separate new discovery.

There are O(k) differences per cell and soft-k² explicit incidences across all colour/scales. That acquisition rate is not accepted as a whole-query advance. The issue below is whether their actual starts admit a better joint product, including the carry.

## 2. A canonical carry can be removed for this enlarged factoring predicate

Fix b!=0 in one difference cell. Let a_b be its least admitted a in(-A,A), with canonical lambda_b, and set

    a=a_b+k*t, 0<=t<L_b,
    x_b=beta^(a_b+bN+lambda_b), R=beta^[k(1−j)].

The exact canonical node is

    x_(b,t)=x_b R^t q^c(t),
    c(t)=ceil(j*t/k−lambda_b/H), 0<=c(t)<=t.        (1)

Thus a canonical comparison x_(b,t)=q^n is an unwrapped comparison x_b R^t=q^(n−c(t)). Put Lmax=max_b L_b=O(k/B+1). Replace every moving clock by the COMMON interval

    -Lmax+1 <= v <= W.                             (2)

This is a COVERAGE-PRESERVING SUPERSET, not a numerical product identity. Unlike an arbitrary dropped-carry substitution, every new zero here is legally decodable. The unwrapped exponent label is

    K=a_b+bN+lambda_b+k(1−j)t−Hv.

Its difference from bN is bounded explicitly by14k³+4H: |a_b|<2H, lambda_b<H, t<=4k and |v|<=10k+1. This is below N>256k^4 on k>16. Hence b!=0 makes K nonzero for every added comparison. A proper gcd factors; a saturated equality uses K itself, of O(logN) bits, in the old extractor. No correction product is inverted or declared a unit.

For the transpose use x'_b=beta^(b+a_b N+lambda_b) and R'=beta^[k(N−j)]. Its label is aN plus a remainder bounded by14k³+2H+k<N. Every admitted difference has a!=0, so the same nonzero proof applies. The same relative carry c(t) is used because the phase is retained. Thus the two-prime coverage survives this common-envelope operation.

This is an actual finite way to remove row-dependent canonical carries for this ENLARGED factoring predicate, at O(k/B) extra clock positions. It does not prove equality to the original zero-only edge predicate, and its extra collisions need not correspond to original rectangle edges. Their independent nonzero beta labels are the justification.

## 3. Joint string completion is better than independent string calls, but still not enough

For fixed j,B, all b strings have the SAME R and the same enlarged q-clock. Their lengths L_b take only two adjacent values. Group by each length L, and acquire

    G_L(Z)=product_(t=0)^(L−1)(1−R^t Z),

in soft L by an actual product tree. There are O(B) acquired starts x_b and two such kernels. The scalar readout is a product of G_L(x_b q^-v) over the common interval(2), apart from known monomial units. This is initialized polynomial/geometric multipoint data; it does not require acquisition of all B*L nodes.

Use the inherited polynomial block method: a clock baby block of length d has coefficient degree Ld, and is evaluated at O(B*K/d) actual starts, where K=O(k+Lmax)=O(k). Kernel construction and monic evaluation cost

    soft(Ld+B*K/d+B+L).

Clipping d at1 and K as necessary and optimizing gives

    soft(B+L+sqrt(L*B*K))=soft k                    (3)

per cell, since LB=O(k). No inverse of1−R^h, a collision value or a node difference occurs. R may have small order. Prefix clocks can be clipped by the same construction, and the final selected cell can be explicitly materialized for the existing recovery consumer.

This improves the STRING-BY-STRING completion soft(k+k sqrtB) recorded in the concurrent report, by sharing the kernel and clock across b. It does not improve the already known soft-k per-cell completion, nor the soft-k² explicit whole-family algorithm. Its compressed initialization can be only O(B+L) for one cell, but its remaining block scalar work is still soft k. I have not found a recursive identity amortizing that readout across all colours/weights.

The exact commensurability R^k=q^(1−j) is retained. It does not mean R is a kth root of unity. Folding its t-index by this relation changes the q-clock interval; it must keep the changed endpoints. In particular it cannot delete the unknown scalar in(3) as an auxiliary cyclic normalization. The public cell filter does not provide such a norm identity; the supersuperset here can instead use all nonaxis difference cells as above.

## 4. The new pure Cartesian Gauss-basis family: execute its scalar, not just its description

The concurrent `sparse-projection.md` supplies a cleaner input, whose coverage/filter proof is separate: two acquired units X,Y per public colour/weight cell, Cartesian differences |r|<A, |s|<B, (r,s)!=(0,0), AB=O(k), and common clock h=0,...,4k. Its filtered leaves have nonzero short beta labels. No canonical point carry remains because the generator phases define a genuinely unwrapped character. This is therefore a legitimate finite three-geometric-parameter product, rather than an analogy with an unmasked rectangle.

An actual initialized scalar algorithm is obtained by constructing

    H_cell(Z)=product_(|r|<A,|s|<B,(r,s)!=(0,0))
                         (1−Z X^r Y^s).           (4)

It has degree D=(2A−1)(2B−1)−1=O(k), a unit leading coefficient and O(k) actual input factors. Product-tree acquisition costs soft k. Its scalar query is product_(h=0)^(4k) H_cell(q^-h), acquired by monic evaluation/block products in soft(D+sqrt(Dk))=soft k. This includes the potentially singular h=0 comparisons. The origin factor is omitted BEFORE specialization, not divided out of a zero full box. Repeated numerical monomials are allowed; a nonunit is handled with its own supplied short label.

The same cost follows from explicit multi-axis blocking: a kernel with v factors is evaluated at O(V/v) starts, where V=O(ABk)=O(k²); choosing v around sqrtV gives soft k. Recursive product reuse, without a new scalar identity, realizes this old square-root-volume completion. It is not a logarithmic-time three-dimensional norm algorithm.

Combining all cells into the common-q polynomial product of their H_cell gives degree soft k²; acquiring those coefficients and its clock query remains soft k². Alternatively summing the per-cell algorithms gives that same bound. This is a charged completion, not a lower bound on a different implicit joint evaluator. It is already slower than the retained original soft-k^(5/4) query.
