# Removing balance from the paid collision setup

This packet proves a conditional extractor and setup for every semiprime at the sixth-root scale. The central long-query acquisition remains open. These are independently reviewed classical bit-complexity arguments; no new Lean theorem or complete sixth-rate factoring algorithm is claimed.

Let N=P Q, m=Theta(N^(1/6)), N<=m^6 and B=16m². A supplied unit gamma has odd local orders greater than B. Given ANY supplied nonzero global annihilator K of polylogarithmic binary length, the new extractor factors N in soft O(N^(31/192)) bits, which is below N^(1/6). Neither factor balance nor either individual index bound is supplied. The previous extractor required both local indices below m.

The key change is to use the small-order separator with only ONE small local order. A public dyadic bin X<=P<2X bounds the smaller prime's index by 2X/B. A cheap initial Jacobi-minus scan handles equal local two-adic valuations; otherwise a nonresidue at the prime with the larger valuation separates the powered orders. Wrong bins are harmless. The worst-bin cost is

 soft O((N/X)^(5/32) sqrt(X/B)) <= soft O(N^(31/192)).

The separator and the Burgess least-nonresidue theorem are inherited. The new paid composition removes the balance and both-small-index assumptions, with all scans, modular powers, gcds, bin choices and a finite-input fallback charged. It does not acquire K.

This also removes balance from the setup itself. Harvey--Hittmeir plus ordinary monic small-order detection either factors N or supplies large odd local orders. In the common-full-order branch a computed r>B satisfies r³>4096N, hence P+Q<r² and (N+1) mod r² recovers the factor sum even for unequal factors. Projection by N-1 gives coprime local orders; if that projection is globally trivial, the explicitly acquired K=N-1 feeds the new extractor. A further paid check certifies q=beta^(m²) local orders above B.

Consequently, for ALL semiprimes the preparation costs soft O(m) and returns a factor or a unit beta with odd coprime local orders above B, global order above B², and q local orders above B. Parity and square checks handle the elementary cases. No numerical local orders are known or required.

The old canonical denominator-one coverage works for this beta: its own-factor index lies in 0,...,2m²+1 using only the post-prefix bound and N<=m^6. Integer-offset deduplication supplies unit target differences. Any globally colliding bounded leaf recovers P+Q=1+m²i-delta, using the global-order margin and the new unbalanced factor-sum bound. These are inherited native arithmetic mechanisms instantiated classically, not newly compiled beta-controller theorems.

The exact remaining sufficient interface is a restriction-stable product or witness query for J=O(m) targets against L=2m²+2 consecutive q-powers. A soft O(m)-bit restricted evaluator would close the classical all-semiprime pipeline by logarithmically many gcd/bisection calls. A scalar zero without restrictions or witness information does not provide that contract. The existing general product clock is still soft O(J+sqrt(JL))=soft O(m^(3/2)); no improvement to it is obtained here. Full acquisition and the complete Lean bit-complexity proof remain necessary.
