## Formula-to-code audit

The base acquire supplies the already reviewed U,D,E0 and scalar pair descriptors. The normalized core sets gamma=t², computes V=t^m U²D^(−m), and uses V_inverse=bar(V)gamma^(−m), exactly from Vbar(V)=gamma^m. It acquires qh=V^m and qh_inverse=bar(qh)gamma^(−m²), with W_s=qh^(−s),s=0,1,2. Pair descriptors multiply these vectors by gamma^(N+a). Whole=gamma^(A+Nh)qh^(−S) and weighted_A=(V/gamma)^A match the independently checked normalized formulas. No full family of separate pair/row vectors is generated by the core; the selected expansion helper is test-only.

The exposed ce_inverse first rejects even pg.k. That restriction is necessary because the used D/D_E Gauss-pair formulas rely on odd character orders and chi(−1)=1; it is now enforced even when calling the helper independently of acquire_normalized. Odd order1 remains valid. Negative E is rejected consistently with the underlying quotient API. If supplied coefficients are given, their length is checked and their semantic contract is that they are the actual C_E, not an arbitrary unit vector.

The helper forms the FULL E-th-power-trivial projector, DE=E_E+ell(1−E_E), and returns bar(C_E)DE D^(−E). Thus E=0, unit E, nonunit E modulo composite m, multiples of m, and all lower-order character components are retained correctly. It does not substitute E0 for E_E or replace D by ell at the trivial character. No generic polynomial inverse is assumed. At a nontrivial component trivialized by E, DE is1; elsewhere it is ell. This exactly matches C_Ebar(C_E)=D^E/DE.

## Public inputs, signed powers and costs

Input t is reduced modulo N, so negative supplied unit representatives are legitimate. A proper gcd(t,N) returns a genuine public factor; gcd=N returns the explicit SATURATED_PUBLIC_UNIT status and no spurious factor. Unit t makes gamma a unit, legitimizing every scalar negative power. The imported primewise screens retain the public m/ell gcd repair. The implementation does not claim to certify prepared odd orders; that remains an external input contract.

The wrapper reconstructs a second public PackedGauss table, adding another soft O(ell) cost, not a hidden per-row setup. It uses constant-many rank-m vector powers and O(m) scalar/index descriptors. Nine normalized output vectors are counted, including intentionally shared/duplicated W_1=qh_inverse; the imported constant-many base outputs add only another O(m) storage term. Parameter exponents are polynomial-size in the native regime, so signed scalar powers and vector powering have only logarithmic overhead. The ce_inverse helper is soft O(ell+m) when acquiring C_E, or soft O(m) given the actual coefficient vector, with logarithmic exponent/bit factors. The implementation report explicitly limits the theoretical bound to fast-integer accounting and does not certify Python/GMP timing.
