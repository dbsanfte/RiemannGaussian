# Actual scan/copy auxiliary frames and outer clock erasure

Two NEW modules only; prior sources remain unchanged.

`SourceMemoryTrace` records actual readWord frames, following its actual nonzero Boolean and actual subBits decrement. Each visited frame retains original address, copied visited word, test Boolean, decremented bits (empty when not executed), actual returned word, pending memory tail, subtraction borrow and actual enclosing/auxiliary report counters (including every subtraction gate/read/write/test counter). This covers return-frame data, not just persistent memory stores; pending tails are expanded and counted without a sharing assumption. Frame count is ≤M; every original address/decrement ≤B and word payload ≤W. All actual stored counters sum to ≤twice the enclosing read report. The ledger charges their magnitudes plus constructor cells conservatively; an explicit Nat.size lemma also bounds their binary payloads. The total field view is bounded by M*(M*(2W+2)+4W+2B+2(M+1)(8W+15B+30)+19).

`copyReturns` follows the actual copyMemory recursion and records EVERY return report including the empty return. Its M+1 returned lists/counters have total field view ≤(M+1)*(M*(2W+1)+M+M*(8W+9)+4). Keeping all duplicate suffix lists is conservative and does not assume in-place mutation/GC. No valid-rational premise is needed for shape bounds; width is the legitimate original physical input contract.

`SourceProgramErasure` defines executable outer-report-free read/copy/step/run functions and proves exact equality to the original complete physical output for ALL inputs, no fits/correctness oracle. Tests, decrement bits and arithmetic outputs use the actual existing Boolean backend. Original high-level Nat clock sums are absent. Arithmetic/test primitive report internals are NOT erased here; projecting their outputs can still invoke those report implementations. An unused copied visit in a positive scan may be removed by compiler dead-code elimination; no claim of identical lower-level operation traces is made, only exact physical outputs and shared Boolean/address recursion.

The same module defines stepAuxCells/programAuxCells using the actual instruction/memory recursion, combining both scan traces, copy returns and real step/recursive report counters.
