## Executed data path

`coefficients Lbits` executes rawAddBits(unsigned L, literal −1) once, acquiring L−1. Its four-word selector returns literal1, that actual predecessor, unsigned L, literal−1. No native signed integer is encoded. `featurePairs` is the static sixteen row-major pairs of Fin4; it is not the obsolete original M² score-term list.

For each pair, `term` calls the actual histogram producer once, caches that State, physically multiplies the two acquired coefficients and its unsigned histogram bits, and retains State.clock and both raw multiplication reports. `sumTerms` literally traverses the sixteen pairs; every actual term/child/rawAddBits report is retained. `incidence` acquires coefficients once, performs that sum and physically multiplies by the cache's actual L² word.

All subtraction and cancellation is signed physical arithmetic. Numerators may be negative. No GCD/reduceBits call, semantic value decoding, native count encoding or unknown modular inverse is in this runtime. `DenOne` proves actual denominator VALUE one for every coefficient, term, sum and final incidence. Untrimmed denominator padding remains physically paid by raw operators.

`incidence_value` proves the exact output

```
(bitValue cache.square:Q) * Σf,g coefficient(L,f)*coefficient(L,g)*bitValue(hist f g).bits.
```

The concurrently supplied original feature producer and original-sums theorem instantiate these histogram reports; this internal arithmetic function itself does not pretend an arbitrary callback proves original-source acquisition.

## Head and original weighted score

It caches borrowed views of their already acquired words, so repeated use does not repeat their source producers. It executes raw physical products/additions and sign-bit negation for

```
L⁴*(C+q*f) + G*q*(2*p*f+f²−f).

In particular f²−f is honest signed subtraction; f=0 does not invoke truncated Nat subtraction. `fromState` wraps an actual histogram State as a denominator-one word while retaining its whole clock.

`weighted cache I H` physically computes cache.weights.incidence*I + cache.weights.head*H, retaining both complete lane reports. Exact value/denominator/validity and source-clock retention theorems are provided. No positivity of n,M,lambda or either weight is needed for these arithmetic identities.
