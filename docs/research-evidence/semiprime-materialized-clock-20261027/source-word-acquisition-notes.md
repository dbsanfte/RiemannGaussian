# Original-source labels from an actual finite score interpreter

NEW sources only: `SemiprimeMaterializedScoreEnvironment.lean`,
`SemiprimeMaterializedScoreSearch.lean`, `SemiprimeMaterializedSourceWords.lean`.
Root's Words/WordSearch and the earlier six modules remain unchanged.

## Closed interfaces

The previous generic driver accepted a terminal `omega -> Run Rat` and its
semantic/budget contracts. These NEW routines compute the original terminal
instead. A `ScoreProgram` holds four numeric codes for incidence head/slot
collisions, or two numeric codes and an interpolation coordinate for head
collisions. `compile` obtains every code by an actual first-position index-list
scan; `compileAll` caches the reports/programs once. Supports are then literal
instruction fields (length <=4), with no further source-index search.

`Environment` consists of a concrete reverse-prefix list of cached word arrays,
a cached default, and a newest-first local override list. The interpreter
executes both override and prefix scans. At local expectation depth <=4 there
are at most four overrides. `equalCoordinates` actually reads/compares all Q
cached coordinates. No arbitrary assignment function is a runtime terminal
input. The proof-only `denote` exactly matches the old decoder and functional
updates.

`ScoreSearch.expectation/evaluate/sequential/search` execute all local
completions, finite averages, term sums, candidate comparisons and sequential
choices. They reuse the existing actual `assign` loop with the NEW real
objective constructor. Score values are the original x^2 or y^2 collision
indicators; signs, tie-breaking and reverse-prefix order are unchanged.
The work bounds derive an explicit terminalBudget; no free hp/B terminal
premise is present.

`SourceWords.producer owner factor a tail terms indices x y` returns

    SourceUniversal.Run (I -> SourceUniversal.Run (UniversalType r Q 1)).

It constructs the ORIGINAL offset itself using an explicit r^(2Q) integer
power loop, executes the whole source label search ONCE, and returns a paid
per-incidence constructor capturing that computed list. Each request executes
two numeric index scans and two reverse-prefix label reads. The precise
semantic endpoint is `producer_value`: its label is EXACTLY the incidence type
of original `Packing.computedWords`, not merely a label with a comparable score.
`producer_work` is bounded by `producerBudget tail.length terms.length
indices.length Q`; each incidence request is bounded by

    4*indices.length + 6*(indices.length+1)^2 + 7.

Qhol's original-source adapter owns using this actual producer once before
materialized packing/source arrays. It therefore need not assume a final label
or a terminal-score answer.

## Resource scope and a rational-height calculation

The Lean theorems prove exact values and the selected scalar/array/list-control
ledger. They do NOT assert a complete primitive word-address/bit clock. In
particular, materializing a candidate `Word` executes Q coordinate calls; the
trace counts these explicit calls. For the actual finite source word list,
words are generated by Q nested `Fin.cons` constructors, so refinement can pay
an additional O(Q) per coordinate lookup. No arbitrary user omega is assigned
unit cost. Input enumeration construction, finite-type metadata, original
owner/factor access, structural equality, physical arrays/addresses and rational
bit normalization retain their separately stated refinement costs.

The following elementary rational-height argument is explanatory, not a new
Lean height theorem. Suppose r>=1, the alphabet length A>=1, and x,y have
integer denominators dx,dy. Each actual terminal is 0,x^2,or y^2. A local
expectation has at most four divisions by A, and every partial sum at the same
depth has the same denominator. A common denominator for all local score loops
and the actual offset is therefore

    Delta = (dx*dy)^2 * A^4 * r * r^(2Q).

This includes intermediate terminal products and every partial average/term
sum. The search carries only words between objective calls, so denominator
depth does not accumulate across the N choices. A generous absolute-value
bound for all rational objective partials is

    (T+1)*(A+1)^4*(|x|+|y|+1)^2*(M+n+Q+1)^4,

where M is incidence count, n is original variable count, and T the term count.
Multiplying by Delta bounds integer numerators. Thus bit heights are polynomial
in input rational heights, Q log(r+1), log(A+1), and logarithms of the finite
network dimensions. The actual symbolic power loop's integer heights are
O(Q log(r+1)). This justifies a subsequent polynomial bit refinement, but is not
claimed as an already compiled primitive program in this slice.

## Runtime control

`SourceWordSmoke.lean` forces execution of the new producer on an exact two-
incidence finite source. It returns heads0,1/sharedslot0 and the computed label
array agrees with old `computedWords` (`true`). This is a tiny deterministic
interpreter diagnostic, not a factoring campaign, coverage proof by examples,
or asymptotic speed evidence. The all-input correspondence is the theorem.
