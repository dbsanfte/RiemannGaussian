# Materialized acquisition and formal rate, 2026-10-27

Goal **ACTIVE**. This packet advances the Lean execution proof of the existing
paper-level deterministic N^o(1) factoring route. It does not yet prove the
complete original-input primitive bit clock. Subexponential storage is permitted;
no practical speedup or improved native long-query acquisition bound is claimed.

The useful new results are structural, rather than additional successful examples:

- The source search now executes the actual collision and head scores from
  cached word arrays, reverse-prefix and short override lists. Numeric support
  descriptors and offset powers are acquired. The output is proved to be exactly
  the original deterministic word assignment, with a fixed polynomial
  scalar/list-control bound and no terminal-score or final-label answer input.
- Packing addresses, all universal interpolation arrays and the original
  incidence-by-variable coefficient family are acquired and cached through
  explicit finite scans. Their value and work theorems compose. The final
  original-input execution uses this new supplier; the separate selected-design
  constructor still requires its complete cost attachment. The final endpoint is
  `SemiprimeCachedSourceScheduledExecution.run`.
- Local head words and their integer measurements are materialized once per
  node. The full support and summary traversal uses these tables, invokes the
  original local factors and executes Hermite scalar reconstruction. No product
  of all global Boolean assignments is enumerated. Exact correctness connects
  the new execution to factor recovery for every natural input.
- The actual selector state has a shared original integer pivot-minor
  denominator. Its stored rational numerators and denominators are bounded by
  2^[n(n+b)] from b-bit integer input entries. All residual, normalization and
  update scalar temporaries also have polynomial widths. The executed physical
  inverse-and-multiply normalization has a proved bit-operation bound.
- The literal scheduled support count, actual summary cardinality and head
  sizes, and public growing scopes are bounded by a subexponential resource
  envelope. Every fixed polynomial in this envelope is eventually below N^ε
  for every ε>0, including ε=1/6. This closes the rate half; it does not replace
  the outstanding proof that the complete run has such a polynomial bit cost.
