**Conclusion: the composed negative/conditional conclusion is sound. No sixth-rate factorizer has been acquired.** The rigorous factoring source supplies an appropriate subexponential time scale; the conventional implementations still retain linear bitspace. The shallow Dixon construction remains conditional, and its demonstrated reusable-randomness evaluator is outside the fresh-coin family103 model. The following qualifications should survive integration.

1. **Promise correctness is not the obstacle.** The family103 fixed capped interpreter has an acceptance probability on every input, even when that probability lies between the decision thresholds. Its total deterministic probability approximator/separator can therefore act on a semiprime-promise source, provided time/space caps hold on every input and correctness gaps are required only on promised inputs. State this directly; do not claim that an arbitrary promise source is a total BPL-language witness. Enforcing cutoffs supplies the resource totality needed for this use. The exact probability equality under virtual padding is not conditioned on the semiprime promise.

2. **Output needs an explicit bit interface.** For semiprimes with distinct prime factors, every verified nontrivial divisor can be normalized to the same smaller prime `min(d,N/d)`. A source/circuit for its i-th bit, accepting only on verified successful output, has a bounded-error gap after constant-success amplification. Invoke the deterministic estimator separately for i=0,...,n−1 and emit each bit to a write-only output tape. The index counter costs O(log n) bits and the number of invocations adds only polynomial(n) time. Do not materialize or reread an uncharged n-bit factor. In the proposed circuit route, bitwise normalization, exact division/comparison and verification must themselves be supplied by the local uniform circuit construction and covered by its resource ledger. They are not granted by the success predicate alone. If both factors are requested, the second factor also needs such an output-bit interface. For general integers, independently chosen valid divisors need not agree bitwise; the semiprime canonicalization argument must not silently be generalized. The separate accepting-run extraction is available only after a valid fresh-coin source is established.

3. **The parameter balance is correct, conditionally.** For `B=exp(n^alpha)`, the proposed costs are `tildeO(n^(1−alpha))` for log trial count and `tildeO(n^(2alpha))` for factor-base linear-algebra depth. The exponent `max(1−alpha,2alpha)` is minimized at alpha=1/3, yielding 2/3. Thus the anticipated `Q=S+log T+log n` is `tildeO(n^(2/3))`, **only if** the remaining circuit construction, all-output-bit access, gate uniformity, `log R`, `log Z`, and `U_S+log U_T` fit that budget. This optimization does not establish those missing circuit bounds or success analysis.

4. **The read-p target follows exactly from the primary theorem.** Cheng–Wu v3 Corollary6 gives time `2^O(p(S+log(n+T))) poly(n,T,1/epsilon)` for additive acceptance-probability estimation on every input. At fixed epsilon, the sufficient condition is `pQ=o(n)`. If the completed construction establishes `Q=O(n^(2/3)(log n)^c)`, a sufficient target is `p=o(n^(1/3)/(log n)^c)`. With unspecified logarithmic losses, write `p=o(n^(1/3)/polylog n)` as a target, not an established bound. Count physical visits while crossing intermediate random-tape cells as well as intentional queries; only consecutive stays at one cell are coalesced by the theorem. Circuit depth and an oblivious DFS schedule do not bound p. This route would use Cheng–Wu directly and does not need family103.

5. **Compiler arithmetic checked.** From the family103 formulas `P=1000(d+2)^4(a+b+2)`, `rho=100(P+2)`, `Sigma=1+(t+1)(2rho+1)(g+2)`, `c=2Sigma+1`, with d>=1, t>=4 auxiliary tapes and g>=2, one gets `Sigma>=4000P+8021`, hence `c>=648000000(a+b+2)+16043`. The external-padding deduction `delta c>=648000000 sigma` for `S_alg>=sigma log₂N` is correct for this reported certificate. It is a lower bound on a very loose **upper-bound exponent**, not a runtime lower bound or impossibility theorem. The finite library constants are not numerically instantiated by the PDF.

6. **Virtual input is charged correctly if its symbols are reproducible.** For fixed program length d, `D=100(d+1)^3` and `Lambda=max(ceil(log₂(T+1)),D(S_alg+2),ceil(log₂(L_pre+1)),d,2)` suffice for a virtual input of length `2^Lambda`. Its address, interpreter state and simultaneous callback scratch use O(Lambda+log n) bits; prefix regeneration costs polynomial(n,Lambda) per query. A fixed total separator then yields the conditional `2^O(S_alg+log T+log n)` resource implication. The virtual padded string is deterministic input, regenerated from the real input and fixed program. It cannot conceal an arbitrary random assignment on a free read-only tape: regenerating reused random bits is exactly the unclosed model issue in the Dixon route.

The substantive proved implication is therefore: **assuming the family103 theorem, a fixed fresh-coin verified-factor source with S=o(n) and log T=o(n) admits deterministic N^o(1) simulation, with output handled explicitly.** The literature/circuit work has not supplied that source. Alternatively, the proposed reusable-randomness circuit could suffice if completed with the stated small read-p bound, but that bound remains unproved. Neither implication is an implemented or fully proved factorization algorithm.
