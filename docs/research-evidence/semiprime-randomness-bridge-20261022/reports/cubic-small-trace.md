# Cubic-budget small-trace acquisition attempt

Let r be a supplied public prime of size N^(1/18), with gcd(r,N)=1; individual gcd screens return a factor otherwise. The total permitted acquisition work is soft O(r^3), followed by the reviewed sparse-residue consumer. I read constructive-frontier-index.json and the frozen composite-character normalization review before this pass. No frozen files changed.

## Correct sufficient datum and a minor alternative

The actual ordinary trace S=P+Q mod r gives at most TWO factor residues: solve x^2-Sx+N=0 mod r using an O(r) public root table. There is no need to lift a catalog modulo r^2. With J<=2,n=r the inherited consumer term N^(1/5)(J/r)^(3/5) is soft O(N^(1/6)). A public Fermat quotient q_r(N) is a different datum and is not substituted for S.

An alternative sufficient symmetric datum is T=P^2+Q^2 mod r. Then S^2=T+2N; enumerate at most two S and at most two roots for each, hence at most FOUR factor residues. Equivalently, the ratio trace P/Q+Q/P determines T after multiplication by N. This tolerates a sign/inversion ambiguity if an actual character/trace extractor naturally produces it, but no such extractor is claimed here.

## Concrete use of the larger budget: the whole small N-power table

Set A=(Z/NZ)[X]/(Phi_r(X)), rank r-1. A single modular Nth power costs soft O(r), including logarithmic exponentiation factors. Thus one can actually acquire O(r^2) designated N-power evaluations within soft O(r^3); for example choose r explicit elements a_i=X^i+i (reduced modulo Phi_r) and acquire every (a_i+a_j)^N as well as a_i^N. Their additive defects

 D_ij=(a_i+a_j)^N-a_i^N-a_j^N

form an O(r^3)-coefficient data set, fully paid. No hidden characteristic is needed to compute it. Guarded dense rank/ring elimination or coefficient gcd tests can expose a proper scalar factor if the resulting local supports differ appropriately. These are legitimate arithmetic operations over the composite ring, not a split-field oracle.

This table does NOT have a proved tag/trace extraction rule. Modulo P, Nth powering is Qth powering composed with the actual Frobenius rho_(P mod r), and Qth powering is generally not additive. A nonzero D_ij may be nonzero modulo BOTH primes, giving scalar gcd1. Merely finding a failed primality congruence is therefore not a factor-producing witness. I did not prove a rank discrepancy, kernel separator or interpolation theorem forcing such a witness for this acquired table. Declaring Nth powering to be the unknown Frobenius would incorrectly erase this exact distinction.

There is also a concrete compression fact for the seemingly larger small Gauss table. In a character algebra of odd order r with g_E indexed modulo r and C_E=g_1^E/g_E, define U=g_1^r. Then exactly

 C_(E+r)=U C_E.

Thus all E up to r^2, although affordable here with straightforward repeated powers, are generated by the r residue vectors and U. The extra table does not by itself identify a hidden prime's character action. All trivial-character/projector exceptions in the frozen packet remain necessary. This observation only explains that particular attempted use of the extra budget; it is not a statement that cubic rank-r algorithms cannot extract the trace.

## Primary Frobenius/character theorem actually inspected

I inspected Schoof, *Four primality testing algorithms*, arXiv:0801.3840, https://arxiv.org/pdf/0801.3840 , Theorem2.1 and its Frobenius proof, and Section3 Proposition3.1/Theorem3.2 with the algorithm following it (PDF pp5–6,10–12). The character theorem requires explicit cyclotomic congruences and an additional l-adic condition. On success it constrains each hidden prime's character to a power of the public character of N, with a still-unknown exponent. The primality algorithm then enumerates a common power catalog. Neither theorem says that a failed congruence supplies a factor or computes the hidden exponent. This is precisely the hypothesis gap in using the paid table above as a universal trace extractor.

The original APR primary paper was opened at its author-hosted 34-page PDF, https://math.dartmouth.edu/~carlp/PDF/paper37.pdf ; browser text extraction failed, so no additional claim here is attributed to its full text. The concrete theorem statements used above were inspected in Schoof's primary exposition, not inferred from an APR abstract.

## Exact remaining cubic primitive

The paid rank-r table supplies explicit matrices/vectors. A sufficient completion would be a deterministic soft O(r^3) procedure producing either a scalar factor of N or an O(1)-size menu containing S (or T) from those data, with a proved guarantee for EVERY semiprime. An alternative is a guarded Frobenius equalizer whose whole-local kernel necessarily differs between P and Q, plus an explicit scalar factor descent. Its matrix entries and construction would need to come from these actually acquired N-power data, not from an assumed rho_P.

I did not construct that separator or trace decoder. The increased budget genuinely pays dense rank-r tables and all small character directions, but this pass yields no all-input rule converting them into P+Q mod r. The exact improved reduction to a squared trace is available if a future extractor naturally has only sign ambiguity. The goal of a universal sixth-rate factorizer remains unmet by this branch; no impossibility or lower-bound claim is made.
