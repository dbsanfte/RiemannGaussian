## 1. A native reflection preserving the exponent modulo H

Write c=bN and e=a+c+lambda, with lambda²−4ac=0 modH. Before choosing canonical representatives define

    R_a:(a,c,lambda) -> (a+2lambda+4c, c, −lambda−4c). (1)

Direct expansion proves BOTH

    lambda_new²−4a_new c = lambda²−4ac,
    a_new+c+lambda_new=e.                           (2)

Reduce lambda_new into[0,H). Reduce a_new moduloH into the signed band 0<|a_new b|<k, if such a lift exists. The band has span<2k<H, so this lift is unique. Accept the edge only if its entire image is an actually retained catalogue row; otherwise keep the original row unpaired. The image lambda is still even. No fake free-variable root or out-of-band row is introduced. Since (1) is an involution moduloH and canonical lifts are unique, accepted edges are disjoint pairs or fixed points.

Let a'=a+2lambda+4bN−H U and lambda'=−lambda−4bN+H V. Then the actual acquired labels obey

    E'=E+H delta, delta=V−U.

Because b is unchanged,

    |E'−E|=|(a'−a)+(lambda'−lambda)|<2k+H<2H,

so delta is EXACTLY one of −1,0,+1. All coefficients, carries and lookup tests cost soft J, using O(logN)-bit integers. If prior unit-certified diagonal/axis pruning removed an image, no coverage claim for that missing edge is needed: keep its surviving source row unchanged. Public deletion and original recovery metadata are not reversed.

This supplies a real native parameter operation underlying SOME q-shifted row targets. The previous report correctly found no supplied global shift taking every row to q times itself; (1) is a partial reflection with an explicit admissibility test, not that missing global shift theorem.

## 2. Execute the finite exchange and charge its endpoints

The empty prefix m=0 is handled directly. For m>=1, set the negative-only row kernel

    A_m(E)=product_(i=1)^m(beta^E−q^-i), y=beta^E.

If E'=E+H, then

    (y−q^-1) A_m(E+H)
       =q^m (y−q^(-(m+1))) A_m(E).                  (3)

Instead use squarefree-N zero/nonunit semantics: A_m(E)A_m(E+H) has the same local zero bit at each prime as A_(m+1)(E). Its interior factors occur twice rather than once, but their presence is identical. Consequently global-zero and gcd-with-N bits are preserved. Every merged endpoint has an original label. In the delta=+1 case index m+1 is row E+H at its original index m; index1 is row E at index1; shared interior indices have either stored source. ## 4. Carry-aware polarization on actual low-a phases

For 3 not dividing b put S=H/4, c_b=(bN)^-1 modS. Choose integer phase corners t_00=mu, t_10=mu+nu, t_01=mu+omega, t_11=mu+nu+omega. Define the acquired integers

    tauhat_ab=(c_b*t_ab²−a_ab)/S,

The actual row labels have the exact form

    E_ab=bN+c_b*t_ab²+2t_ab−S*kappa_ab.

    beta^E_11 beta^E_00
      =beta^(2c_b nu omega) rho^(-Delta kappa)
