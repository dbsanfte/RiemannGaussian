# Block arrays, padded constraints and explicit expression bounds

Root-owned new modules are BlockArrayExecution, SourceArrayAcquisition, PaddedBlockExecution, PaddedBlockCoverage and SourceExpressionBound (all with the Semiprime prefix). Every semantic polynomial/layout occurs only in proof statements. Runtime inputs are finite words, maps, enumerations, integer/rational scalars and arrays.

BlockArrayExecution replaces the source's mathematical extension-by-zero with the computed packing lookup. Two incidences in the same complete block use the actual universal coefficient callback. Other block coordinates are zero, and uncovered incidences retain their singleton identity row. An explicit incidence enumeration computes the original-variable owner pullback. The specification proves literal equality to LayoutBlocks.assembledRow and LayoutPullback.row; its work ledger keeps every invoked array callback.

SourceArrayAcquisition supplies that callback from the computed binomial parity/universal interpolation program, so no coefficient is an argument. `acquire` caches M by n arrays in explicit incidence order. `read` is total with empty defaults, and acquire_read proves those defaults are never used for constructed valid coordinates. acquire_coefficient identifies every retained source coefficient. The actual Lean original-source smoke executes packing, acquisition and reads, producing the expected identity leftovers on a two-coordinate control.

PaddedBlockExecution implements integer owner sums using List.ofFn and the explicitly enumerated finite equivalence. Runtime indices are `(Fin blockCount × UniversalType) ⊕ I`, constructed by product/sum lists. Invalid universal rows and inactive leftover candidates are zero. PaddedBlockCoverage compares them with the source's noncomputable finite reindexing strictly in proofs: each old row is present, and each new row is zero or old. Generic cardinal injectivity proves `indices.length ≤ 2*incidences.length`. SourceConstraintAcquisition subsequently transports these exact covers to the original owner pullback.

SourceExpressionBound counts the ACTUAL syntax tree: summation and product each add one operation node per list entry; basis≤6Q+5, correction≤6Q²+8Q+1, and complete mismatch interpolation≤6Q²+8Q+3. Combining this with the cached compiler gives the explicit universal array budget and then the original source owner-pullback budget. This does not charge creating the syntax/constants or the finite source search, and is deliberately named array work rather than whole acquisition time.

One ordinary-root lint found an unused explicit Fintype I argument in assembled_spec. It was removed and BlockArray/SourceArray were rebuilt; final audits cover the repaired source. This is a proof-interface cleanup, not a runtime change. The all-module audit and isolated rechecks, rather than interim build logs, are the acceptance evidence.
