# Frontier after actual source-to-scalar acquisition

The missing source-value oracle is now removed: the counter receives only the original indexed network and its local integer tables, with public finite parameters. Source coefficient arrays, padded integer rows, selected measurements, representative/fibre packets and Hermite samples are computed. The new correctness endpoint is universal over such input networks under explicit numerical precision and source-height guards; it is not a certificate for a finite list of semiprimes.

The source matrix is not an arbitrary dense global operator. Its padded candidate count is at most twice the incidence count; its selected rank equals the existing semantic source rank. The earlier summary-size/rank argument therefore remains applicable. Source coefficients may be materialized because their M*n*(R+1) size is polynomial on the schedule. This is separate from the much larger Boolean summary/support/truth traversals that must remain streamed.

## Next proof target

Make a single resource-bearing executable wrapper around `AcquiredSourceCounter.count` that charges source/design preprocessing AND the bit-backed local/group/fibre/support/Hermite program. Refinement must preserve the value of the current counter, and its clock must follow the actual loops and storage rather than attach an arbitrary sufficiently large counter to an uninstrumented computation.

The relevant inputs are now concrete:

* binomial integer solver with tracked arithmetic/read operations and all-prefix integer bounds;
* actual finite source expression with exact quadratic tree-size bound and coefficient-array work bound;
* original integer matrix with explicit padded row coverage, source-derived entry bound and actual selected rank;
* literal restricted-table local execution with common-denominator bounds for every recursive suffix/branch/product/subtotal;
* earlier global fibre/support/Hermite bounds and physical rational word primitives.

Remaining primitive attachments include finite word and subset enumeration; conditional-expectation score evaluation; lazy label/packing and selected-row recomputation; source-expression constant generation and intermediate arrays; Gaussian scratch rational operations; function/equivalence/finite-set lookups; summary decoding; entry evaluator callbacks; memory copying and retained data. A fixed polynomial overhead on the scheduled numerical dimensions is sufficient for the candidate exponent, but it must be established for the executed path. The independent paper audit supplies a roadmap, not that Lean theorem.

After this wrapper, connect the public equality-subdivided graph descriptors and entry checker. Compose original Boolean count semantics and prefix recovery rather than importing a desired count as an input. Derive the scheduled guard for sufficiently large inputs and include the explicit finite fallback. Only the resulting all-input theorem can close the guaranteed 1/6-or-better factoring objective.

The whole-source execution controls (1,2,0) are useful because an earlier frontend had a proof-only polynomial index leak. They certify neither a new asymptotic rate nor semiprime-family coverage. No extra finite-success campaign is needed.
