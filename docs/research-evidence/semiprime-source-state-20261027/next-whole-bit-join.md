# Remaining whole-bit join after the new source-state proofs

The remaining work has changed materially. Final universal/source-row height cannot now be called the missing invariant: the NEW modules bound actual difference frames, contribution products, integer sum suffixes, interpolation subtrees/convolution slices, source-array pullback suffixes and actual original coefficient readers. The new integer family also has original acquired cell/read/mask bounds. These results still do not constitute an all-state machine theorem.

## Actual caller bindings now available

* `SourceScoreState.callerScore` is literally the sequential callback in `MaterializedSourceWords.producer/computedList`, including `compileAll`, the actual initial/alphabet words and `offsetRun(card I,n,...)`. The conversion `card I=en.incidences.length` is explicit in its proof. All search prefixes are quantified; canonical comparison cross-products have bounds.
* `SourceOffsetHeight` treats each power prefix and a proof-side list of the fixed offset expression's operand/intermediate values. Its scale/offset caller lemmas derive data from original epsilon/schedule. The list is a view of those scalar stages, not a new evaluated offset backend or a complete register trace.
* `SourceUniversalHeight` and `SourceConstraintHeight/State` bind the actual cached parity vector, finite difference tree, subsets, all right-recursive integer sums, cached universal reads, original owner sums, dense table cells, four-scan reads and head mask. Arbitrary acquired addresses/producers are harmless to these magnitude bounds, since every copy branch is a bounded read or literal zero/one. No terminal matrix answer is supplied.
* `SourceInterpolationHeight` binds actual source constants and AST node cap; `SourceCodeArrayHeight` bounds every compiled subtree and multiply prefix/slice. `SourceAcquiredArrayState` discharges the generic `CacheBound` premise from that actual constructor and propagates it to original acquisition, every owner suffix, the frame-array view and the actual incidence reader. Generic `SourcePullbackHeight` alone did not discharge that premise; the new specialization does.

## Precise next obligations

1. **One reachable-source-state envelope, including scalar sizes.** Assemble the new statements at the actual scheduled source call sites, instead of claiming that separate extensional theorems already describe a whole operational state. Prove an original-resource polynomial bound for the *bit lengths* of their denominator/numerator envelopes. With J=R+1, source interpolation uses D0=`2^(R-1)*Q!`, N=`6Q²+8Q+3`, common denominator D0^N and numerator `base(J,D0,B0)^N`; `B0=D0*(Q+2^entryExponent+1)`. These are exponential values with polynomial bit exponents, not polynomial scalar magnitudes. A≤Q is available only on the actual lawful/fast branch. `SourceAcquiredArrayBits` NOW proves the original suffix and literal incidence-reader dyadic bounds, explicit successor-aware canonical bit lengths, and a fixed original-resource polynomial/monomial envelope for M+1+stateBits. Its generic reduced-array theorem also applies to the proved callback/frame array view. Thus this original-array numeric bit-height join is achieved, not a remaining conjecture. What remains is an aggregate reachable-state binding covering the other scalar/container/control state and its simulation; these results must not be mistaken for all machine state.

2. **Pascal/target supplier attachment and scalar inverse construction.** `acquired_kernel_bound`, `acquired_target_bound`, `acquired_solve_prefix_bound` and `acquired_dot_prefix_bound` refer to the literal acquired kernel/target caches. The existing `acquireChoose_value/chooseRow_bound` can be instantiated at every Pascal depth A'≤A, and `acquireLower_next/value` at every target depth≤R. An explicit aggregate state/cell theorem for `acquireChoose`, `acquireLower`, `sign`, `solve` and their temporary products has not been supplied merely by those pointwise corollaries. Likewise the actual source `NodeUnits.ofField` node/difference inverse constants and denominator unit construction now have rational value bounds, but their inversion/power/normalization instructions still need primitive implementations or the generic arithmetic simulation below.

3. **All metadata and live/persistent cells, not just payload rectangles.** Exact scalar counts now include universal integer QD², universal rational D²(R+1), original rational Mn(R+1), original dense integer Q*r*p*n and pullback callback/return view `(2M+1)(R+1)`. They do not count a complete heap. `SourceSearchState` NOW supplies actual cached-word colour IDs, search-output bank membership/length, original-index bounds, at most four overrides per local frame, per-frame coordinate counts, and descriptor-bank constructor/field cells≤5T. It additionally attaches total expectation override-coordinate allocations and sequential prefix/completion-coordinate allocations directly to their ACTUAL `.work`, not an assumed storage answer. Its indexed sizes are N=n+F, T=M²+Q*n², L=r^Q and U=r^(2Q). These particular search/score metadata obligations are achieved. Still attach a whole-heap bound for `PaidFiniteEnumerationLists.words/copyWord`, `PaidFiniteEnumerations.indexed`, original label/address tables and `MaterializedSourceWords.labelAt`, `MaterializedPacking.labels/bucket/minimum/position/place/acquire`, `PaidPackingSnapshot.acquire`, `PaidConstraintAcquisition.blockNames/names`, AST construction and copied array/list/descriptor prefixes. The score descriptor count is achieved; enumeration/packing/function-closure descriptors and the aggregate heap are not thereby counted. A word has Q coordinates each<r; a universal type has two such words. Bucket/block/position IDs must be bounded by actual list lengths (M/D/p), not assumed unit-cost opaque values. Include simultaneous old/new Pascal and array prefixes, recursive return frames and closure/descriptor storage. Sharing may reduce these counts, but no unproved sharing premise is required: a conservative bound polynomial in the explicit materialized dimensions is enough.

4. **Attach scalar and address primitives to these ACTUAL programs.** Existing work reports count selected arithmetic/list/control events. Source production still performs Nat/Int/Rat arithmetic and canonical `q.num/q.den` access as scalar operations. Supply either a refinement of those finite programs to existing physical primitives, or a deterministic simulation theorem for their explicit instruction language. Schoolbook integer operations/GCD, rational add/mul/inverse and scan-based indexed lookup have fixed-polynomial costs in proved operand bits and stored cells; the theorem must bind actual instructions and outputs, not assume its desired cost/state oracle. Raw numerator/denominator temporaries follow from operand bit caps, but this deduction must be attached. Array allocation, copies, equality of finite words, arithmetic on IDs, loop counters and pointer/address traversal must remain charged. Permitting subexponential materialization avoids the old polynomial-space implementation difficulty; it does not make addresses free.

5. **Finish the original public control path.** Literal bitLength/clog/sqrt/powers/schedule/fastGuard operations, original public graph/enumeration generation, final physical rational-word conversion/floor, prefix controller and operand decoder require the same primitive/control simulation. Existing all-input semantics and eventual fast guard already avoid a new factoring argument. The finite fallback need not have the asymptotic fast bound, since the proved guard eventually selects the fast branch. Its correctness remains part of the all-input caller.

Once (1)–(5) yield a bound by a *fixed polynomial* of the existing public resources and their proved bit/storage envelopes, apply `PublicResourceRate.polynomial_subpower` to that complete new simulation. `HermiteFullReportRate` already proves subpower for the actual retained physical-Hermite report, which is a substantive input. It is not by itself the complete primitive-bit theorem; no old/new clock equality is needed or justified. There is no new long-query identity or empirical factoring campaign required by this next join.
