# Executed universal and integer-cache preprocessing heights

Two NEW modules extend only proof interfaces of the frozen executed source programs. No alternate parity solver, supplied numerator value or desired state-height premise is introduced.

`SourceUniversalHeight` proves that actual delta registers are literally 0 or 1. Induction on the actual two-branch `difference` gives absolute value at most `2^positions.length`; `difference_frame_abs` permits every dropped suffix and any accumulated swapped argument. Every scalar `powerTwo` prefix is bounded by its original exponent cap. The pre-difference multiplication and complete subset contribution are bounded separately, before cancellation.

`sumRuns_abs`, `sumRuns_suffix_abs` and `sumRuns_prefix_abs` bound actual recursive sum values by literal remaining term count times the callback cap. `inner_suffix_abs` and `outer_suffix_abs` instantiate them on the actual subset materialization and actual parity-index list. These cover right-recursive entry frames, rather than inferring scratch bounds from the final entry's source identity.

The original supplier's acquired parity has coefficient cap `2^E`, where

```
E=R*(A+clog 2 (R+1)+1).
entryExponent A Q R=E+2R+2Q.
```

The table entry cap is `2^entryExponent`. Its bit exponent is bounded by the explicit polynomial `R*(A+R+2)+2R+2Q`, including zero dimensions. `extended_acquired_abs` and `extended_parity_abs` deliver the same cap to the actual interpolation frontend. They identify the already executed cached parity vector, not an advised vector.

Additional corollaries instantiate the existing binomial bounds on the literal `acquireChoose` kernel, `acquireLower` target cache, every actual `solve ... len` prefix and every `dot ... len m` prefix. They use the original `BinomialExecutionBounds` backend; no second solve is built. These new corollaries cover coefficient/target/solve/dot integer magnitudes, while the existing module supplies Pascal and retained lower-next identities.

`table_cell_abs` bounds every scalar actually stored in the three-level table. Its shape is exactly Q matrices, each D rows and each D columns for D=`words.length`; `table_scalar_cells` proves exactly QD² integer cells. This counts scalar payload cells, not a complete machine allocation/pointer layout or maximum live stack.

`SourceConstraintHeight` propagates the cap through the actual `PaidConstraintCache.acquire/read` and `PaidConstraintRows.copy` calls. The acquired clearing denominator is at most `2^R`. The difference before normalization and all zero-extension/block-address branches have cap `2^(entryExponent+R+1)`; leftover identity branches are explicitly 0/1. Exact cached scalar-cell count remains QD².

These are scalar-state height and concrete table-shape invariants. They do not by themselves attach bit primitives to scalar source arithmetic, bound all interpolation AST/convolution states, address/pointer/descriptor bits, or the complete original-input execution. The adjacent source offset, interpolation compiler and owner-pullback accumulators require their own actual-prefix invariants. The full primitive-bit 1/6 goal remains open until those bounds and the complete simulation/cost join are attached.
