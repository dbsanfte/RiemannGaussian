# Independent review: paid N-power order-loss screen

26 October2026. The proposed prepass is correct under the original native hard-branch contract. It factors exactly the exceptional case P | ord_Q(q), and otherwise certifies that N-powering is an automorphism on both local q-subgroups. It also certifies the same for the beta-subgroups. This is a preparation result, not a whole-query acceleration or a novelty claim.

## Exact inequalities and branch classification

Let P<Q, A=16k²+1, B=floor(N/A²), and w=q^N. The source contract gives N<=k^6 and P,Q>16k², hence P>=A, Q>A and N>A², so B>=1. Also

    B <= N/A² < k²/256 <16k².

Because r_P=ord_P(q) divides P−1 and Q>P, gcd(N,r_P)=1. Consequently ord_P(w)=r_P>16k²>B, and no factor w^j−1, 1<=j<=B, vanishes moduloP.

Since r_Q divides Q−1, its gcd with N is either1 orP. Thus

    ord_Q(w)=r_Q                  if P does not divide r_Q,
    ord_Q(w)=r_Q/P                if P divides r_Q.

This formula needs no assertion about v_P(r_Q): N contains P only once. The proposed auxiliary assertion v_P(r_Q)<=1 is nevertheless true here: Q=N/P<k^4/16 while P²>256k^4, so Q<P² and P² cannot divide Q−1.

In the exceptional case,

    r_Q/P <= (Q−1)/P < Q/P=N/P² <=N/A²,

so its integer value lies in[1,B]. In the other case it exceeds16k²>B. Therefore, for Z=product_(j=1)^B(w^j−1),

    gcd(Z,N)=Q   iff P divides r_Q,
    gcd(Z,N)=1   otherwise.

There is no saturated gcd branch, no need to locate an individual leaf, and no order/exponent factorization is assumed. Cross-prime coprimality of r_P,r_Q and oddness are not needed for this screen's classification, although retained from setup.

## Paid exact computation of Z

Set b=ceil sqrtB and t=floor(B/b), and acquire

    P_b(X)=product_(r=1)^b(w^r X−1).

Build its actual linear-factor product tree in soft O(b) ring operations; the kernel's leading coefficient is the known unit w^(b(b+1)/2), although kernel monicity is not required. Evaluate at the t acquired points X_h=w^(hb), 0<=h<t, by monic subproduct/remainder trees. The point polynomials are monic regardless of repetitions or zero divisors. No inverse of a node difference, kernel value, or 1−w^r is used. Its values multiply to the product over1<=j<=tb. Acquire the remaining B−tb<b scalar factors at w^(tb+1),...,w^B and multiply them in. This exactly includes endpoint B, including when b divides B.

Kernel coefficients, node powers, values, final products and gcd cost soft O(b+t+log N)=soft O(sqrtB+1) ring/bit scale with polylog N factors; powering q^N is also polylogarithmic. Since sqrtB<k/16, total bit cost and residue storage are soft O(k). In this setting “monic BSGS” properly refers to the monic evaluation divisors; the displayed P_b itself is generally nonmonic with unit leading coefficient. Normalizing it is optional and harmless.

## What a failed scan certifies

A gcd1 result excludes P|r_Q, and the other possible cross-divisibility Q|r_P was already impossible from Q>P. Therefore

    gcd(N,r_P*r_Q)=1.

For each local cyclic group generated by q, exponentiation by N is consequently an automorphism, preserving equality, distinctness, element orders, and local collision tests when applied to both sides. No public inverse exponent is acquired by that certificate; any algorithm needing to invert the automorphism explicitly must still supply a method.

This also extends to the local beta-subgroups. If D=ord(beta), then ord(beta^H)=D/gcd(D,H); D/ord(q) divides H. Since gcd(N,H)=1 on the hard branch, gcd(N,ord(q))=1 implies gcd(N,D)=1. The same holds for eta and any subgroup of beta. Thus the claimed larger-component order-loss issue is repaired without silently replacing q by a different subgroup. The screen does not itself preserve a short integer annihilator label under every subsequent construction; later labels must still be checked for nonzero value and paid bit length.
