# Axis controller: paid residue tradeoffs and an exact arbitrary-hit kernel bridge

26 October 2026. Read the scalar catalogue, the hybrid coverage-selector,
old coarse-factor-residue completion, the factor-correlated Euclidean
packet, mutation-coverage and the new boundary audit. Paper only; no tests,
campaign, factoring code, Lean or repository changes.

**Positive completed operations:** (i) a public logarithmic family of
known-residue controllers factors the quantified smooth-ramification
subclass in soft k; (ii) any useful ODD-phase axis collision, even an
accidental modular alias, transports exactly to a nonliteral universal-
kernel b=0 hit and its phase residue transports to a clock residue.
Neither supplies a residue on all remaining semiprimes. A fixed public
N residue cannot force the required growing +/-1 ramification; the
specific next-step congruence test below proves that assertion precisely.
The known-residue and factorial algorithms are prior credit, not a new
factoring exponent.

## 1. Public factor bound and a covered adaptive axis query

Let H=k^2, q=beta^H and rho=beta^k, so q=rho^k. The hard scalar
contract gives large odd beta/q orders and P,Q>16H. For a PUBLIC
factor bound B<=sqrt N set

    M_B=ceil(B/k)+1.

Consider horizontal a=k,b=0, lambda=t*k and I in [-M_B,M_B].
Retain only ODD t in [0,k): this preserves the genuine smaller-factor
witness

    t=[-P]_k, I=(P+t)/k, 1<=I<=M_B.

Its normalized leaf is

    1-rho^e, e=t+1-kI,
    beta label k*e,
    e=1-P at the genuine witness.                  (1)

Omit every literal e=0 BEFORE evaluation. The witness has e!=0. All
other added or accidental nonunit leaves have their own nonzero short
beta labels, so a proper gcd finishes or the licensed extractor applies
once. This is a COVERED FACTORING query for inputs with P<=B, not a
claim that every located phase is the actual P residue.

Whole-row deletions in the original family are not ignored: restoring
only nonliteral leaves of E=Hi0 adds certified units when the old
short-window bound applies. Alternatively the newly defined punctured
query is a licensed nonzero-label factoring overcover. It need not equal
the smaller stationary-colour product as a scalar or predicate.

## 2. Execute a phase-residue subquery and its cost

Take an odd power m=3^u dividing k, and an acquired phase residue
v modulo m. Odd t with t=v modm are one class t=v_odd mod2m,
where v_odd is the unique odd lift. Put d=2m, so d|k, and write

    t=v_odd+d*j, 0<=j<k/d.

As I traverses its consecutive interval, the integers
j-(k/d)I tile ONE consecutive interval. Thus (1) is one geometric
product of base rho^d, length

    O(k*M_B/d)=O(B/m+k/m),

with at most one literal-zero split. No order of rho^d is presumed;
the inherited monic division-free geometric engine gives

    soft O(sqrt(B/m)+sqrt(k/m)+T_ext).              (2)

For an explicitly acquired S-residue palette containing some useful
axis collision phase, joint variable-window evaluation gives the paid
upper bound

    soft O(S+sqrt(S*(B+k)/m)+T_ext).                (3)

All phases, starts, literal splits and localized short labels are
included. The palette ACQUISITION cost must be added. Listing all m
residues supplies coverage but restores the old soft sqrt B bound.
For the gamma family B=Theta(k^(2+gamma)), a useful one-residue supplier
with m>=constant*k^gamma would make (2) fit soft k. This is a weaker
supplier target than the generic sqrt k modulus in the old all-size
factor-residue decoder, but is NOT a supplied output here.

An index residue I=w modm instead gives k/2 odd-phase starts and an
AP clock of length O(M_B/m+1). The joint old engine costs
soft O(k+sqrt(B/m)+T_ext). It is also target-rate when m>=B/k^2.
This is another actual paid consumer, not a claimed algorithm reading I.

## 3. Complete PUBLIC +/-1 residue controllers

For each odd power m=3^u<=k/2, choose a public cap

    B_m=min(floor(sqrt N), floor(c*k^2*m)),

where c>0 is a fixed constant. Run the two phase subqueries

    t=-1 modm and t=+1 modm,

with the bound B_m. If P=+1 modm the first contains the genuine
witness; if P=-1 modm the second does. Every attempt has bounded
soft k cost by (2), and there are O(log k) choices. Wrong residues
return only a verified factor or a unit/failure; no promise recognition
is presumed. Consequently this complete public controller factors
whenever

    P <= c*k^2*g_odd,
    g_odd=max(gcd(P-1,k/2),gcd(P+1,k/2)).

This is the exact odd-power threshold; no factor-two convention is
needed. All caps and residues are explicitly acquired. A standalone
additive AP product of integers n=+/-1 modm through B_m supplies the
same subclass and rate; it does not need beta at all. Thus this is
integration of OLD known-residue/AP factorial machinery, not a new
factoring result. The old scalar controller, content/smooth grouping,
and coarse-residue literature already supply the underlying operations.
The narrow duplicate search found no prior claim that this subclass
covered ALL remaining axis cases.

At fixed gamma>0 this helps only if the relevant gcd grows at least
k^gamma. It includes polylogarithmic/smooth subregimes, but the actual
unbalanced regime is not uniformly discharged by this controller.

## 4. N's public residue does NOT force that ramification

This is an exact modular statement, not a distribution claim about
actual factors. For EVERY unit N modulo k with e>=2 there exists a
compatible odd unit pair j,c modulo k with jc=N and

    max(gcd(j-1,k),gcd(j+1,k),
        gcd(c-1,k),gcd(c+1,k))=6.                   (4)

To prove it, choose both residues modulo9 from
S={2,4,5,7}. For each possible N modulo9, the following seed pair
has product N:

    Nmod9: 1  2  4  5  7  8
    (j,c): (2,5),(4,5),(2,2),(2,7),(4,4),(2,4).

All elements of S have exactly one of +/-1 divisible by3, with that
valuation exactly one. Lift j arbitrarily to an odd unit modulo k and
set c=N*j^(-1) modk. The same mod9 seeds persist, proving (4).
Hence factor congruences supplied by N modulo k alone do not imply a
power-growing +/-1 gcd, even allowing either factor and either sign.
This does NOT prove that every such residue pair is realized by prime
divisors of a fixed N or that a stronger global integer filter fails.
It isolates the missing arithmetic input in this public-ramification
controller. It is stronger than only observing N=1mod3 and choosing
independent fake roots.

## 5. Exact axis-to-universal-kernel bridge, including arbitrary aliases

This bridge does NOT assume a located axis hit is stationary. For ANY
nonliteral useful leaf in the ODD-phase query (1), e is even, and
locally rho^e=1. Therefore

    q^(e/2)=(rho^e)^(k/2)=1.                       (5)

It transports to universal kernel b=0 with

    h=e/2=(t+1-kI)/2 !=0,
    |h| <= (k*M_B+k)/2 <= (B+3k)/2.               (6)

If the public bounds satisfy (B+3k)/2<=W, this is literally an
included leaf of the already covered universal query; otherwise it
is an explicitly bounded b=0 extension with the same own-label decoder.
The gamma family with gamma<1/2 satisfies the inclusion asymptotically.
For any odd m|k, (6) gives the EXACT residue handoff

    h=(t+1)*2^(-1) modm.                           (7)

Thus a phase-residue supplier for ANY useful odd-axis alias gives a
kernel clock-residue supplier without falsely interpreting its phase
as -P modk. The original b=0 kernel factor is 1-q^(-h), whereas (5) used
q^h=1. It differs from 1-q^h by the unit -q^(-h), so both its
zero and nonunit predicates agree. The corresponding signed beta
label is -H*e/2, or its negative, an integer nonzero short label;
saturated global zeros remain legal, and no accidental scalar zero
is assigned a factor tag. At the true stationary axis witness the
identity specializes to h=(1-P)/2, but (5)-(7) are stronger because
they do not need that provenance.

With b=0 known and the shorter bound (B+3k)/2, the one-row AP consumer
costs soft sqrt(B/m)+T_ext, matching (2). If the FULL universal W clock
is kept, its requirement is instead m>=W/k^2, which can be larger.
This distinction prevents crediting the shorter axis bound as though
it applied to all unknown proof vectors. An I-residue by itself does
not determine (7) without phase information; its direct axis consumer
from Section2 remains legitimate.

The bridge removes an interface mismatch, not the supplier wall.
Publicly trying every phase residue again restores the old square-root
cost. Nothing in (5) computes t modulo m or supplies it from N alone.

## 6. Continued-fraction and known-factor-residue comparison

The old bounded known-P-residue decoder is already in the journal at
43117 and costs soft(1+N^(1/4)/m), with PAID high-interval enumeration.
It must not be called on an arbitrary modular axis phase: such a phase
can be an alias and need not equal -P modulo m. Equation (7) is the
safe replacement for that invalid tag handoff.

A direct integer-AP controller GIVEN the CORRECT P residue and cap B
costs soft sqrt(B/m), exactly the parameter-specific classical tradeoff
above. Unknown-divisor Coppersmith/LLL can alternatively use bins with
cost proportional to B/N^(beta^2) divided by m, including its slack and
all starts; this is the old coarse completion, not a residue supplier.
No hidden polylogarithmic small-root call is made without enumerating
its candidate blocks. The earlier factor-correlated bivariate audit
also pays the shifted coefficient height N*epsilon/k; it cannot be
imported with height N to get a false sixth-rate shortcut.

For the elementary Lehman balancing proposal let R=Q/P=N/P^2.
An integer multiplier a near R balances aP and Q. In the gamma axis
range, R=Theta(k^(2-2gamma))>k. Literal enumeration of the dyadic
multiplier range therefore already has more than k starts, before
near-square windows and tests. A continued-fraction calculation of
N/P^2 has P as its missing input; it is not a public short word.
This charges only that naive construction. Modern Lehman/BSGS
algorithms can avoid such literal enumeration, but no inspected primary
specialization yields a new all-axis soft-k controller here.

Primary context: [Hittmeir, A babystep-giantstep method for faster
deterministic integer factorization](https://doi.org/10.1090/mcom/3313),
Math.Comp.87(2018),2915-2935; and the actually used

## Outcome

The public +/-1 controllers are completed and have quantified coverage,

## 7. Actual low-ramification factor family, beyond modular-lift diagnostics

The preceding failure of the GUARANTEED +/-1 coverage condition also
occurs for actual semiprimes in the gamma family. Fix 0<gamma<1/2 and
choose both primes in the earlier intervals but now in class 23 mod36:

    P in (64*k^(2+gamma),128*k^(2+gamma)),
    Q in (k^(4-gamma)/32768,k^(4-gamma)/16384),
    P=Q=23 mod36.

These intervals contain the stated primes for all sufficiently large k.
The same primary BMOR Theorem1.2 applies with modulus36, phi(36)=12:
its dyadic theta difference is at least

    x/12-3x/(840 log x), x>=8*10^9.

This bound exceeds log(2x) for all sufficiently large x. The theta
increment therefore cannot consist solely of a possible endpoint
prime at 2x; there is a prime in the OPEN interval (x,2x). A prime
at x is not counted in that increment. Thus the displayed strict
factor intervals, rather than only half-open ones, are justified.

The downloaded theorem and source pins are in the prior
`boundary-self-audit.md`; no example-prime computation is required.
The N range and native least-k argument are unchanged.

For either prime p, v3(p-1)=0 and v3(p+1)=1, hence

    max(gcd(p-1,k),gcd(p+1,k))=6,
    max(gcd(p-1,k/2),gcd(p+1,k/2))=3.

Since P/H tends to infinity, no fixed constant c in Section3's
GUARANTEED residue criterion covers this family eventually. Both
primes remain 11 mod12, so odd-part generators and q orders retain
the large-order compatibility described in the boundary audit.
This makes low +/-1 ramification a real arithmetic residual regime,
not merely an uninstantiated pair of compatible modular lifts.

Scope: this does NOT prove that running those modular/axis AP tests
returns units on these N. Accidental modular hits, or multiples of a
factor in an additive AP product, can still yield valid factors even
without P=+/-1 modm. It proves the specific stationary/known-residue
coverage CERTIFICATE does not guarantee a hit there. Nor does it
exclude a different public residue palette, a stronger factor controller,
or force the current scalar controller to continue on every member.
The supplier direction therefore remains genuinely open; all-semiprime
failure is not inferred from this scoped family.
