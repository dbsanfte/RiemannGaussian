# Actual native group callback

NativeGroupExecution materializes original-coordinate Boolean base bits in an actual Array.ofFn and traverses the explicit FinF factor list with productList. Assigned factors execute nativeLocal, which itself caches all corrected port arrays; other factors execute oneRun. No native group value, fibre count or H value is an input. Source coefficient families are concrete read-only arrays with source-degree/coefficient specifications; their original layout acquisition remains outside this callback.

nativeGroup_node_spec identifies the executed arrays with EXISTING CounterSeparation.groupValue/groupedRows/nativeCorrection for ANY NodeCertificate. The proof uses the exact baseBits versus splitAssignment finite-set identity, so Function.update of grouped representative bits supplied by the fibre scanner is already supported. No type transport to special Group/Local types or whole-answer assumption is needed.

The work bound adds a polynomial FinF multiplier to the existing localBudget, including nativeLocal source-shift acquisition and all table EntryReport callbacks. The Run.control field contains an explicit conservative logical control/allocation charge; this remains an abstract operation ledger, not a primitive-TM implementation proof or a bound for arbitrary expensive grouping/source functions. Concrete finite cached lookup/control refinements belong in the final execution composition.
