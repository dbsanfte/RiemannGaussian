# Remaining original-input runtime composition

The goal is still a guaranteed whole-family 1/6 or better bit-time algorithm. A theorem about a finite sample of semiprimes, an arithmetic-operation bound alone, or a value specification with its desired answer supplied is not the acceptance condition.

## Closed in this slice

* Computable finite source enumerations, indexed variable/port transport, complete packing search adapters and mixed-radix summary decoding.
* Computed original-row selection with exact span/rank/independence, tracked rational elimination, and a native design adapter using those selected integer rows.
* Actual representative search and all local measurement/forced scans, with no complete global assignment traversal.
* Source coefficients to shifted corrected inputs, paid local table interpolation, group/fibre/support arrays, and scalar Hermite reconstruction. The final program is proved to return originalContraction from those inputs; all node acquisition callback work is retained.

## Still required

1. Execute and bound the WHOLE source-row coefficient supplier: finite universal words, score preparation, public layout/guards, original constraints, binomial/interpolation solve and rational polynomial arrays. ExecutedNodeDesign is a computable function, but invoking its lazy fields can repeat elimination/filtering. Materialize or pay those calls explicitly. The old EnumeratedCounter remains a mathematical wrapper.
2. Attach the source/local/fibre/support/Hermite height invariants to every actual new interpreter prefix. The original full-factor truth-mask lemma cannot simply be used for recursive suffix tensors: apply the generic local-evaluator representation theorem to each restricted table/suffix and pad common denominators. Source-Horner intermediate heights and RREF scratch bounds need their own explicit attachments.
3. Replace the abstract scalar/read/selected-control ledger by the actual integer/rational bit primitive execution, finite-index/set/decoder operations, source/design reads and storage/copy control. Polynomial finite-encoding overhead is sufficient, but it must be proved for one composed run. No constant-time arbitrary rational arithmetic or free div/mod.
4. Instantiate the executed counter on the public equality-subdivided multiplication graph, attach its actual bounded entry checkers, and compose prefix restriction/recovery with the original-integer decoder. The existing semantic original-factor correspondence is useful input, not a substitute for this executable composition.
5. Compose the public guard, the finite fallback, the asymptotic schedule and successful factor recovery in one all-input bit-complexity theorem. Keep constants depending on fixed choices separate from input-dependent scopes. The numeric constant 16435 remains unpinned; the independent Cq=exp(o(n)) argument does not need it.

The mathematical candidate remains N^o(1), with n=Theta(bitLength N), W=O(n^(3/4)), scheduled small summary/support exponents, and polynomial word widths. The older native long query retains its soft-K^(5/4) bound. This slice supplies no general impossibility result and no new finite-success campaign.
