# Next whole-clock handoff (read-only scope assessment)

The next useful step is a uniform resource/bit-simulation join, rather than rewriting all remaining scalar code as new word interpreters. This is a proposed proof route, not a completed primitive clock theorem.

**Already proved on the actual implementation:** the N-only guarded algorithm has exact all-input factor semantics with a finite fallback. Source enumerations, original coefficient production/encoding, integer constraints, physical row selection/designs, packet evaluation and physical Hermite reconstruction are actually called; their reports are retained through every prefix query and decoding. Original-source common-denominator/numerator theorems and local/packet/Hermite bounds derive arithmetic fits without advice. All new Hermite stages execute physical word arithmetic, including acquired cardinal inputs, cached normalized inverse and chronological accumulation. SetupBudget supplies a closed original-dimension setup/encoding/native bound under explicit actual head/rank/scope/entry caps. Public search bounds multiply an actual counter budget by at most wireCount+1.

**Still missing:** (1) discharge those caps for the literal indexed/physical designs and attach the resulting NEW Hermite report envelope to the scheduled N-only path; old scalar public rate does not transfer by value equality; (2) bound maximum stored integer/rational heights and total stored cells/control state throughout source preprocessing, not merely the final coefficients; (3) account for the actual natural/integer arithmetic in schedules, guards, width calculation, indices, list/array addressing, allocations and report bookkeeping; (4) attach the final word-to-rational interpretation and Nat.floor to a bit implementation. The source producer and rational-to-word num/den extraction remain scalar interfaces. Existing source/row/Taylor/prefix/common-denominator bounds are strong inputs for (2), but their availability is not itself an execution theorem for every preprocessing prefix.

A standard deterministic bit simulation can suffice IF a concrete encoding of this program's finite state and operations is supplied: maximum bit height Lh, total allocated cells S, and executed scalar/control steps T must be derived uniformly from the actual scheduled input. Schoolbook arithmetic and even linear scans give a fixed polynomial overhead in Lh,S,T. Polynomial space is not required: materializing tables is permissible when every table cell and traversal is paid and S itself stays subexponential. Thus one does not need another special-purpose word implementation for every rational scalar operation. Existing physical arithmetic/selector proofs can be reused as sharper subroutines; generic rational normalization, list-copy and index simulation can cover the remaining finite source/control routines.

The quantitative join must prove these resource bounds for THIS algorithm, including repeated source/raw acquisition, independently recomputed metadata/width summaries, callback acquisition, and full final floor. It must not assume memoization of a function closure or treat an unconstructed finite enumeration/table as available. Intermediate height arguments should use common-denominator/product/minor bounds already proved; final-output height alone is insufficient for a Gaussian/elimination or rational source loop.

If the resulting whole bit work is bounded by a fixed polynomial in n,Q,R,J, the actual Y/weightedCount/head-enumeration resources, and their proven bit heights, the established schedule estimates are the appropriate tools to show it is 2^o(bitLength N). A separate theorem must perform that substitution and the eventual N^(1/6) comparison. This packet has not proved those final simulation/substitution theorems; additional leaf-only word backends would not close them by themselves.
