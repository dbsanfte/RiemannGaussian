## Exact x/y caller link

The active callers are `MaterializedOriginalSource.acquire`, `PaidOriginalConstraints.acquire` and `CachedRawConstraints.acquire`. Each uses x=eps*M/A, y=n/(2r), with M=en.incidences.values.length, A=en.types.values.length (the universal-type bank), and the same original eps. `SourceWords.producer` computes its original offset internally, then invokes the actual computed-word search. Earlier files proved exact scale semantics (`scale_eq`) and work, but did not prove these x/y canonical numerator/denominator heights.

NEW `original_scale_representations` derives common D=de*A*(2r) and B=Be*M*(2r)+n*de*A from ORIGINAL eps Representation de/Be. NEW `scheduled_scale_representations` uses actual eps=1/(r*lambda), so de=r*lambda,Be=1 and closed dimension-only D,B. These are not evaluated-score or height answers. The positivity/length substitutions from the actual constructor and fastGuard still need a wrapper theorem; no whole original-source bit-height closure is inferred merely from canonical q.num/q.den.

IMPORTANT: the score averaging alphabet is `wordFirst::wordTail`, of size L=r^Q, whereas the x scale denominator A=en.types.length is the universal-type bank size r^(2Q). These are distinct quantities. With scale common denominator D, the support-four averaging denominator is D²L^4, not D²A^4 unless deliberately enlarged.

The expectation representation remains valid even for an empty alphabet (division by zero evaluates to zero in the existing rational semantics). Reduced-height theorems require positive denominator, and the actual source alphabet is the nonempty `wordFirst::wordTail`. Local support scan bounds use actual remaining.Nodup, which the sequential range' satisfies. All recursive depths are<=4 in actual source score evaluations.
