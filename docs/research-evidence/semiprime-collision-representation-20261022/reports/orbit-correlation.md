## Exact problem and factor guarantee

Let R=Z/N, N=P Q, m odd with public factorization, gcd(m,N)=1. Inputs are two ACTUALLY acquired coefficient vectors A,B in R[X]/(X^m−1). For j in U_m define rho_j(A)(X)=A(X^j). Suppose for at least one j0,

    B=rho_j0(A) modulo P in the WHOLE coefficient algebra,
    B!=rho_j0(A) modulo Q in that algebra.                     (1)

Choose independent uniform r_k in R. Define H_j=<r,B−rho_j(A)>. Acquire all H_j as described below and compute their individual scalar gcds with N. At j0 the hash vanishes modP. Its Q-reduction is uniform because the Q-discrepancy vector has a nonzero coefficient; random r modulo N projects uniformly to F_Q. Thus a proper factor is found with probability at least1−1/Q. All returned factors are verified. Repetition is a Las Vegas expected-soft-m separator UNDER (1); it is not a theorem that native sources force (1).

No whole-algebra equality is inferred from equality at a single character component. Random projection preserves an already given WHOLE local equality. An internal cyclotomic zero divisor may be nonzero at both base primes, so it does not meet (1).

## All unit-tag correlations in soft m

Write the coefficient part as C(j)=sum_k r_(j*k modm) A_k; the alternative inverse orientation yields the required <r,rho_j A> and merely relabels unit j. Partition coefficient indices by d=m/gcd(k,m). Such an index is uniquely k=(m/d)u with u in U_d, including k=0 at d=1. Define A_d(u)=A_(m/d*u), r_d(u)=r_(m/d*u). Then

    C(j)=sum_(d|m) c_d(j mod d),
    c_d(v)=sum_(u in U_d) A_d(u) r_d(v*u).

Each c_d is a finite-abelian-GROUP cross-correlation, not an arbitrary permutation matrix. The total number of its input/output slots is sum_(d|m)phi(d)=m. For odd prime powers p^f, U_(p^f) is cyclic; CRT makes U_d a product of publicly indexed cyclic groups. Generate the tables with primitive roots of each odd p^e: factor p−1 by paid public trial division/sieve, search up to p candidates with polylogarithmic work each, and lift a primitive root to prime powers. Enumeration over all f costs sum_f phi(p^f)=p^e. Summing the public prime-power setup costs soft m. No hidden-characteristic field or discrete logarithm oracle is supplied: all log indices here are generated by enumerating the PUBLIC residue groups.

Finite-abelian-group convolution of n integer slots with O(log N)-bit entries has soft O(n(log N+log n)) bit cost. One implementation is the tensor product DFT on the explicit cyclic factors, computing arbitrary-length one-dimensional transforms via chirp/padded FFTs and rounding the exact integer convolution. Each transform stage pads ONLY its current dimension, not the Cartesian product simultaneously. The operation count is O(n sum_i log n_i)=O(n log n), with O(log N+log n) working bits plus standard guard precision; interval/verified rounding supplies exact integer outputs. There are no assumed roots of unity in R. Modular reduction follows exact convolution. Thus summing all d correlations costs soft m, not m times the number of divisors.

The remaining LIFT-AND-SUM also has a near-linear algorithm; explicitly lifting every c_d separately to U_m could cost phi(m)tau(m), which is NOT the claimed procedure. For each prime power p^e define a truncation tree whose level f nodes are U_(p^f), with a single root at f=0, and parent map reduction modp^(f−1). Total local nodes are 1+sum_(f=1)^e phi(p^f)=p^e. The product of these trees has exactly m nodes, indexed by all pairs (d,u in U_d). Store c_d(u) at its corresponding product node. For each prime factor in turn, make one parent-to-child accumulation pass in that tree coordinate while keeping all others fixed. Every product node has at most one incoming parent in that coordinate. Therefore each pass costs O(m), total O(m omega(m)). The value at the top-level node j in U_m is exactly sum_(d|m)c_d(j mod d), by the product-poset zeta identity. This proves the claimed all-j acquisition without an unpaid divisor-by-tag table.

Subtract from the one acquired scalar <r,B> and take phi(m) gcds. Reading A,B, generating hashes, correlations, group tables, zeta propagation and scalar gcds all fit soft O(m), retaining polylog N factors. No m-by-m output is materialized.

## Deterministic sparse-discrepancy variant

Suppose for a promised j0 in (1), B−rho_j0(A) modQ has at most s nonzero COEFFICIENT positions, where s=polylogm, and P,Q>m. Use s deterministic hash vectors r_k=(k+1)^h for h=0,...,s−1. All hashes vanish modP. If they all vanished modQ, the Vandermonde matrix on the at-most-s distinct nonzero support positions would annihilate their coefficients. Every index difference is a nonzero integer of magnitude<m<Q, hence its determinant is a unit modQ. Contradiction. At least one hash yields a proper factor. The all-tag cost is soft O(ms)=soft m. This is coefficient sparsity in the stated paid basis, not an unspecified sparse representation after an unpaid normal-basis change.

For a coefficient restriction K, set r_k=0 outside K. The same randomized proof applies if the restricted Q-discrepancy is nonzero; the sparse deterministic proof applies on its remaining support. All-j preprocessing still costs soft m. Restricting to a subset of tags simply filters the already computed scalar array, with no new orbit matrix. For repeated restrictions on the SAME A,B, the arrays can be reused. If a restriction changes A or B, or introduces a new unknown seed i, its acquisition is charged anew. This is not yet a soft(|S|+sqrt|I|) rectangle-support routine for arbitrary new seed intervals.

## Concrete low-degree W comparison: paid, but not source-forced

Use the separately derived unit-safe rational W=t(1+gamma X)/(X+gamma), gamma=t². The source assumptions give unit denominators X+gamma and their conjugates. A supplied B=W^N is acquired as ONE packed vector by binary powering in soft m. Clearing the conjugate denominator gives

    (X^j+gamma)(B−rho_j W)
      =(gamma B−t)+(B−t gamma)X^j.                (2)

Let C=gamma B−t and D=B−t gamma. All coefficient hashes of C+X^jD are acquired by ONE ADDITIVE cyclic correlation, plus the common <r,C>. Unit denominators preserve whole-local equality and nonzero discrepancy. Thus (2) supplies a real near-linear separator for the full j-family IF one tag has a whole-local asymmetric equality. Even the multiplicative-group preprocessing above is unnecessary for this particular linear rational family. B and its unit-safe powering are paid; no m separate W conjugates are expanded.

But at the true tag j=P modm, Frobenius gives W^P=rho_j W modulo P, hence

    W^N=(rho_j W)^Q modulo P,

not W^N=rho_j W. Therefore (2) has no proved all-input source supply. The actual native relation, as derived by the torus agent, is

    W^N = rho_j(A_(j,i)),
    A_(j,i)=W^(m²i−ellrow_j) (rho_j W)^(−a_j).

Its A depends on BOTH j and the unknown long index i. Acquiring that whole family before applying the correlation primitive would reintroduce the missing query. No such acquisition is counted as free.

For a fixed public exponent a=O(polylogm), denominator clearing of B−(rho_j W)^a has only O(a) shifted terms, so O(a) additive correlations still give a paid near-linear comparison family. Native a_j can be Theta(m), and ellrow and m²i carry long powers; no reduction to a uniformly polylogarithmic number of common shifted terms was found. This pinpoints a useful next target: exploit the canonical a_j j²=N congruence to obtain such a shared low-term representation WITHOUT discarding high-order scalar carries or the unknown same leaf.
