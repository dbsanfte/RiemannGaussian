# Acquired physical candidate bank and ID-based source selection, 2026-10-27

Status: **original indexed source selection now executes on acquired Boolean IDs; full original-input primitive-bit sixth scaling remains open**.

The new [original-input caller](SemiprimeSourceWordIdCaller.lean) constructs its metadata and score descriptors from original dimensions, arities and owners. It acquires the candidate coordinate bank and ascending Boolean IDs from r,Q, caches the integer weights once, and runs the existing physical-ID choice controller. No native Word, cacheWord, supplied word menu or decoded prefix occurs in this executed selection path. Decoding appears in the theorem proving exact agreement with the original indexed labels and every tie decision.

There is a concrete shortcut: an incidence test uses two physical ID equalities. The acquired bank's injective decoder and the environment's menu-membership invariant prove these are exactly the required word equalities, so those tests avoid reading complete coordinate rows. Head tests still acquire their descriptors and read the actual selected rows and coordinates physically. Concrete Boolean truth, branch additions, normalization padding, lane accumulation, weighting and score comparison supply every selection decision.

The candidate order is proved equal to the actual canonical PaidFiniteEnumerations.indexed order, including zero-first/filter-tail behavior. This is exact ordered equality, rather than a set or permutation argument. The new caller returns the same deterministic original labels after proof-side decoding; arbitrary externally permuted Enumerations are not claimed.

The [actual report bound](SemiprimeSourceWordIdSearchBudget.lean) includes bank/ID acquisition, original metadata and descriptors, cached weights, every score callback, physical comparisons and ID/prefix copies. With M=sum_e arity(e), L=r^Q, U=r^(2Q), T=M^2+Q*n^2 and V=n+F, the [resource theorem](SemiprimeSourceWordIdResources.lean) bounds that actual report by one fixed polynomial in a common cap on n,F,r,Q,lambda,M,L,U,T,V. Its constants precede the entire family. Materialized L,U are explicitly counted; this does not claim they are polynomial in their binary descriptions or establish a new near-linear long-query bound.
