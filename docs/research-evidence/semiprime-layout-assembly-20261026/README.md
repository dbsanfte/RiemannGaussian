# Constructed layout certificates and the concrete macro graph

This checkpoint connects the published generic layout construction to our exact
counter and proves the complete ordered graph wiring. The 1/6-or-better factoring
goal remains active. No complete factoring bit-time theorem or native long-query
acceleration is claimed.

## What is now proved

- `SemiprimeSourceLayout`: actual finite word search, complete bucket blocks,
  universal swap rows, identity leftovers and original-coordinate pullback;
  restoration, degree, balanced heads and total rank are derived for those rows.
- `SemiprimeSourceLayoutHeight`: actual integer constraints have height at most
  `B*2*(8Q)^(2R)`. Universal and block embeddings preserve height; the final
  owner-fibre sum multiplies it by the original occurrence bound B once.
- `SemiprimeLayoutCertificates` and `SemiprimeLayoutSelection`: integer-kernel
  cancellation gives rational row spans. Selecting actual original integer rows
  preserves their height, and explicit signed boxes and representative scans
  supply all local counter certificates. The selected count is the actual rank.
- `SemiprimeConstructedCounter`: original network ports and public dimensions
  construct a `CounterSearch.Problem`. Exact prefix counts, common-witness search,
  empty-result equivalence and at most one count per searched bit plus one follow
  without a supplied layout, row-span, measurement or counting oracle.
- `SemiprimeSourceLayoutRate`: the stronger source load/head/width guards hold
  eventually for the actual integer schedule and growing arity. Literal height,
  summary-box logarithm and inverse-floor bounds are proved.
- `SemiprimeMacroGraph`: concrete ordered endpoint bijections, actual vertex
  scopes, occurrence exactly two, no repeated variable within a scope, equality
  subdivision, exact graph counts and all-vertex arity bounds. The physical carry
  width mismatch is resolved by a proved unique zero extension.

The mathematical counter is constructed for arbitrary finite networks satisfying
the displayed public parameter and occurrence bounds. Quantitative compression
additionally requires the explicit packing and spectral guards. These are not
finite semiprime examples or a finite coverage campaign.

## Quantitative content and its limit

For the actually constructed constraints, selected rank `c` and head sizes `n_g`,
the actual summary tuple has cardinality

`product_g (2*n_g*W+1)^rank_g <= (2*n*W+1)^c`.

The source rank theorem gives `c <= 2*epsilon*M`. For occurrence two and `M=2n`,
the intended schedule uses `epsilon=1/(r*lambda)` and
`W=4*(8Q)^(2R)`. The new rate module proves the literal box bound
`2*n*W+1 <= 2^(6*lambda)` and, given the natural rank budget,

`c*log(box) <= 24*n*log(2)/r
             <= 48*n*nu^2*log(2)/sqrt(lambda)`.

Here `lambda=clog_2(n)` and `nu=clog_2(lambda)`. The constructor's own
Q-1-centered spectral interval is used throughout. This source construction
differs from the earlier Python partial-copy/eigenbasis constructor; its proof
must not be presented as a certification of that unchanged implementation.
In these counter bounds, n counts Boolean coordinates; it is distinct from
the FFT word dimension called n in the macro-graph report.

The exact summary-cardinality theorem is linked to the constructed layout. The
eventual schedule theorem and binary-log envelope are separate compiled results;
a final instantiated network/schedule/primitive-machine theorem is still absent.

Main wrapper, which requires 522 additional modules, was not run. Our seven
new modules do not import that endpoint. They reuse the generic construction.

## What remains before the factoring claim

1. Instantiate every actual ordered local Boolean vertex predicate with the
   multiplication, DFT, normalization, carry and OR semantics already proved in
   separate modules; connect the whole accepted graph to the original factor
   pairs, including source padding, active top-digit width and target digits.
2. Prove the public input-length and balanced macro-parameter bounds, then tie
   the concrete graph's occurrence/arity data to the actual schedule guards.
3. Refine finite enumeration, actual-row selection, Boolean decoding, cached jet
   arithmetic, retained contraction and Hermite recovery to executable loops.
   Charge construction, numerator/denominator growth, primitive bit operations,
   space, fallback and prefix recovery. Mathematical `Classical.choice` or
   `Fintype.equivFin` selection is not an executed routine with a free cost.
4. Compose these into one uniform all-input factoring runtime theorem.

The native long-query soft-K^(5/4) bound is unchanged. This is an alternative
factoring route using the shared counter, not an established soft-K acquisition
algorithm for the original residue query.
