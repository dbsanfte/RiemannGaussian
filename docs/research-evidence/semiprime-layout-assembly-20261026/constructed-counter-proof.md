# Construction-to-counter composition

`SemiprimeConstructedCounter.Parameters` contains only public dimensions,
tolerance, their basic ranges and a bound on original-coordinate occurrences.
The original input consists of arities, ordered coordinates, Boolean local tables
and coordinate coverage. It contains no constructed row, layout existence,
locality, rational row-span, measurement, summary count or answer premise.

The actual incidence type is `Sigma e, Fin(arity e)`. Its owner is the given
coordinate and its factor is the first projection. `layout` applies the finite
word-search/complete-block constructor with default finite enumerations.
`layout_height` derives the integer bound through the actual universal rows,
block copies and bounded owner-fibre pullback. `nodeDesign` selects actual
integer rows and constructs the signed-box/representative certificate.

`sampleEquiv` identifies source indices `Fin Q` with the exact positive rational
nodes used by Hermite recovery. `design` transports each certificate along the
proved equality of node values. The `problem` object derives restoration and
degree directly from its constructed rows. The already compiled counter and
prefix-search identities therefore apply without an external correctness oracle.

The exact output theorems are `constructed_prefix_count`,
`constructed_search_sound`, `constructed_search_none` and
`constructed_search_queries`. Search returns bits from one common original
accepting assignment, or reports absence exactly, using at most `length+1`
calls to the mathematical prefix counter.

The compression ledger also refers to these same actual rows:
`summary_count` is the exact cardinality of the certificate's full tuple type;
`summary_count_le` bounds it by `(2*card(A)*height+1)^totalRank`;
`totalRank_le` applies the published rank proof to the actually built layout.
Its extra premises are explicit original incidence/load/head and spectral-width
guards. The separate eventual schedule proof is not silently converted into a
primitive execution-time claim.

The mathematical definitions use finite choices and enumerations, including
actual-row basis selection and a sample-index equivalence. These must be refined
by concrete algorithms or avoided by equivalent executable representations.
Neither the height of the integer measurement rows nor a finite count of
summaries alone bounds every rational intermediate or proves the running time.

The independent semantic review is `review-layout-counter.md`; the combined
root audit checks all generated declarations of the seven new modules, while
the vendor audit checks every declaration of all 63 reused source modules.
