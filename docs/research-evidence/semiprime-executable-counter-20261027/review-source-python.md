Scope: root reviewed the final six Python implementation/test files recorded in

interfaces they call, and independently replayed both structural test suites.
The review is an implementation/algebra check, not a Lean extraction theorem or
an asymptotic benchmark.

The new constructor follows the pinned generic source construction: exact
conditional means choose variable/factor words; every complete bucket contributes
one full universal copy; unplaced incidences retain identity rows; original
owners receive sums over their actual incidence fibres. Its universal integer
operator excludes the interpolation coordinate and uses the cleared difference
expansion. Its source row interpolates only the prescribed mismatch positions.
The selected measurements are literally original integer constraint rows; the
normalized rational Gaussian scratch pivots are never substituted as measurement
rows. This distinction preserves the integer height used by the summary bound.

minimum among candidate conditional means never increases it. Independent small
completion enumeration checks that conditional mean. A different dense projector
calculation checks 1,600 universal operator entries. Structural cases exercise
complete copies, leftovers, repeated owners and an empty factor; all are clearly
diagnostic and bypass the production guard explicitly. Their small exact tensor
counts test algebraic composition, not whole-family coverage or scaling.

Production guards run before word or matrix allocation. They use exact integer
and rational comparisons, including an integer logarithm upper bound for the
source spectral interval. Optional dimension caps return an explicit no-result
