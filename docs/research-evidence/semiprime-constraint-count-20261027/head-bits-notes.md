# Closed-form physical padded head counter

SourceHeadCountBits.count consumes the actual cached physical power payloads, the physical-ID environment and an original head descriptor. It performs no local word-completion enumeration and constructs no unary L^4 padding multiplier.

The executed branches are:

* identical original variable keys: physically copy cached fourth;
* distinct keys with at least one active: perform both paid native membership scans, then physically copy cached head;
* distinct fixed keys: execute the actual acquired-bank head predicate, then physically copy cached fourth if true, otherwise return the literal empty zero magnitude.

The original metadata equality and membership tests retain explicit native scalar/list-stage costs. All bit payload copies and any original physical predicate report are retained. Power acquisition is a once-per-caller setup cost and is intentionally separate from this per-head report.

count_original fixes BOTH the bank and powers to their actual original-r,Q acquisition. It uses the original physical environment relation and the full exact head_padded_original theorem to prove equality with actual original canonical paddedLocal, for every Nodup remaining list, repeated keys, active arrangement and original environment. No count, encoded power, terminal truth, Fits or desired-output advice occurs. The normalized counts are exactly L^4, L^4/r=r^(4Q−1), and0 as appropriate; no division is executed.

Structural count_length and acquired_length derive the actual copied output width from original cached power widths. The final cap is SourceCountPowers.width rQ=8Q(r+1)+1, independent of L^4. count_original_clock closes all per-head work from original acquired bank, valid-menu environment, fixed/override lengths, original variable-key widths and descriptor/range bounds. Its numeric budget is

```
budget(r,Q,L,N,s)=4N+4*SourceCountPowers.width(r,Q)
                  +SourceWordIdPredicateBounds.terminalBudget(r,Q,L,N,s)+20.
```

The executed original endpoint substitutes L=r^Q; pure budget_mono and budget_monomial give uniform fixed-polynomial envelopes. This conservative bound includes the fixed/fixed physical predicate even when an earlier branch avoids it. It never assumes that predicate's cost, cached values or intermediate fits. No L^m enumeration or unary L^4 acquisition remains in this head callback.

Native original descriptors, equality/membership/control and complete machine allocation/report simulation remain explicit interfaces. The result is an actual head-counter acquisition shortcut, not by itself a public-factorizer or whole primitive-machine sixth-rate theorem. Cached power/setup and outer aggregation must be joined by their callers.
