# Remaining acceptance condition

The target remains a deterministic whole-family factoring algorithm whose total
bit cost is O(N^(1/6)) or better. The shared-summary candidate would be N^o(1).
No completed bound of that kind is claimed by this packet.

Three previous missing input interfaces now have direct proofs: native packet
and prefix coefficient heights, intrinsic Hermite cardinal suppliers, and the
actual public Boolean entry evaluator. The public source-counter value also
joins to ordinary factors, with coverage derived from the actual graph.

The next required result is one tracked execution of the whole counter:

1. Use explicit computable finite encodings/enumerations in the source-layout
   constructor. Identify the conditional-expectation selection, complete buckets,
   integer rows, interpolation and original-row selection with the mathematical
   layout whose rank/restoration properties are already proved. Current generic
   layout correctness allows enumerations, while its convenience wrapper still
   uses noncomputable `defaultEnumerations`.
2. Acquire each concrete H array by the actual bounded-support, summary, head and
   local-truth loops. Prove its value is the native Taylor packet, instantiate
   the new prefix-height lemmas to every retained state, and charge every callback.
   The logical expanded record families used in height proofs must not be
   materialized as the execution algorithm.
3. Compose the bit rational operations, integer descriptors, array/state access
   and controllers with those loops and the Hermite backend. An explicit flat
   binary implementation is sufficient; free Q arithmetic, arbitrary Fin
   evaluation or array lookup is not. The existing backend clocks and paper
   polynomial simulations must be tied to that same execution.
4. Join the exact public guard, finite fallback and original-input prefix
   recovery to the factor-count semantics. Then prove the single all-input
   runtime bound and specialize it below exponent 1/6.

The ordinary operation count, common-denominator estimates, public graph sizes
and eventual guards support that composition, but do not replace it. The finite
fallback needs no computable threshold as advice: the algorithm tests the guard,
and eventual acceptance makes its exceptional input set finite. Optional
diagnostic resource caps cannot appear in the guaranteed-result algorithm.

The newest manual audit is part of the evidence, not a substitute for an
unconditional complete formal execution theorem. The goal remains active.
