# Parametric factor loop: independent review and frame bridge

The root-owned SemiprimeParametricFactorLoop is a faithful command-parametric replacement of the old iterator proof. Its callback is executed, not postulated as an algebraic oracle: CallbackContract includes an actual Eval witness, bounded cost, Good output, step relation, and parser return flags. The loop consumes the original finite ID records; command copies the supplied seed and moves its actual output; assignment executes the real setup/cleanup. No CNF/hash/clause property survives in these proofs. Ready/eligible/step and assignment source/weight obligations remain explicit and must be instantiated.

NEW SemiprimeParametricFactorFrame proves the missing syntactic execution frame separately. The already-compiled original LeafAssignmentRegisterFrame supplies generic parser/copy/setup preservation. Assuming each actual callback execution preserves register i>=16, the new theorem assignment_preserves proves the same for the actual parametric assignment. This assumption is stronger than the restricted CallbackContract and deliberately explicit: the generic dense framed theorem needs preservation for every execution, not merely valid callback starts. A new callback built structurally from low-register primitives can satisfy it without semantic frame induction.

## Simpler time-only materialization route

Yes: if each of the finite parameters Cq, Y, number of group assignments, and 2^w is 2^o(L), every FIXED polynomial in their sum is still 2^o(L). One may materialize finite support/head/assignment/source tables, dense coefficient arrays, and even truth tables on each scope, instead of preserving the original polynomial-space streaming implementation or sharp linear dimension clocks. A product such as Cq*Y*2^w is also 2^o(L); fixed-depth repeated scans and quadratic/cubic elimination do not by themselves destroy the exponent. This uses a time-only target and allows subexponential storage.

This does not license an unbounded polynomial exponent, a table over all L Boolean wires, or a coefficient universe of size 2^Theta(L). In particular the actual sparse dictionary supportUniverse bound and all source precision/dimension parameters still need their quantitative schedule, and rational/finite-ring entry bit lengths must be paid. Likewise a Mathlib finite enumeration or noncomputable choice is not an executable producer merely because its cardinality is small.

The direct route can therefore intentionally pay: materialized macro truth tables 2^w (with actual polynomial-cost checker); explicit source/measurement/bucket lists of their proved subexponential sizes; ordinary polynomial-time linear algebra/interpolation over the compiled finite ring; and generic physical moment/readout loops. This could simplify the remaining producer substantially. It does not eliminate the need for an actual BitProgram adapter, exact corrected-port/source semantics, complete enumeration proofs, precision/count recovery inequalities, or a composed bit-time bound. The new frame bridge closes none of those algebra/cost obligations implicitly.
