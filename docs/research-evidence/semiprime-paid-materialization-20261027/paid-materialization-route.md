# Fully paid materialization: explicit exact counter and paper bit-time result

27 October 2026; read-only investigation. This is a NEW explicit algorithm and paper resource analysis, now instantiated by `paid_integer_counter.py` in this directory. It is not a theorem that the existing lazy Lean run or original SAT machine has this clock. It deliberately relinquishes polynomial space. It uses the exact rational source/counter identities already proved locally, not Theorem D.1 or the SAT endpoint.

## 1. Parameters and exact target

Let L be input bit length, n the original subdivided public graph's Boolean edge count, F its factor count, M total port incidence, and w maximum local arity. The actual public graph has n=Theta(L), F=O(n), M=2n, distinct ordered local ports and w=O(n^(3/4)). Its paid Boolean checker takes poly(L) time per local truth entry. Keep EXACTLY these scopes during prefix recovery.

Use the actual integer schedule lambda=clog_2(n), nu=clog_2(lambda), r=floor(sqrt(lambda)/nu^2), Q=floor(lambda/(128nu)), R=4ceil(sqrt(lambda)), epsilon=1/(r lambda). Test all finite strong source guards; if a guard fails use trial division. The existing SourceLayoutRate eventual-guard proofs make the rejected input lengths a finite set. No unknown threshold, resource cap, or unproved continuation is used.

Write A=r^Q, D=A^2, J=floor(MR/Q)+1, q=J-1, H=max actual head size, C=sum_(j<=q)2^j binom(n,j), and Y=max over sample nodes of the FULL selected integer summary-box cardinality. All are explicit computable integers. Actual selected-row bounds give H<=2n/r and log_2 Y<=24n/r (up to harmless finite rounding already covered by the guard). Here D is the auxiliary universal alphabet size, NOT the measurement radius. Actual integer constraint entries have bound W=2*B*(8Q)^(2R); a head measurement has radius at most nW, so Y is the product of the literal selected-row box sizes (2*nW+1), not a box of radius D. The exact scheduled support proof gives log C=o(n). Also log A, log D=O(log n), so A,D are polynomial in n; more conservatively A,D=exp(o(n)) is already sufficient.

For a deliberately coarse finite bookkeeping variable set

    p = 2+L+n+F+M+Q+R+J+r+A+D,
    S = p+C+Y+2^H+2^w.

Both p and S are public; log S=o(n). In the fixed schedule p is polynomial in n. The algorithm below uses a fixed polynomial in S and p; no loop enumerates functions on a set of size C,Y,A,D,2^H or 2^w. In particular it never enumerates 2^n global Boolean assignments.

## 2. Executable finite construction, including preprocessing

1. Compile the explicit macro graph, ordered ports and original paid truth checkers. Materialize all F Boolean truth tables, using at most F*2^w checker calls. Also cache the at-most-n+1 prefix-restricted tables if desired; restrictions inspect only the existing ports. Keeping the original table plus a prefix mask instead is equivalent.

2. Materialize A words, D universal word pairs, the O(M^2+Qn^2) collision-score terms and all actual variable/factor indices. Compute source words by deterministic conditional expectation. The PINNED `PackingAlgorithm.computedWordsCounted_calls_le` bounds local term evaluations by

    (n+F)*2(A-1)*(M^2+Qn^2)*A^4.

The exponent 4 is important: a score term depends on at most four word labels, not all n+F labels. Index scans, term evaluation and comparison add fixed polynomial factors. The simpler Python conditional_score also has a direct quadratic-pair closed formula; either implementation is polynomial in p. Do NOT brute-force all A^(n+F) labellings.

3. Materialize bucket lists by sorting/scanning the M actual incidence labels; form complete D-block copies and identity leftovers. Construct the literal universal integer numerator operator by finite subset/swap expansion, at most 3^Q terms per entry. Since r>=2, 3^Q<=A^2=D. Materializing its D-by-D tables for all Qr positions therefore costs a fixed polynomial in p. Use the actual cached Pascal/unitriangular parity coefficients, or fraction-free elimination of its explicit R-by-R integer system.

4. Construct Lagrange/source polynomial coefficient arrays explicitly by ordinary polynomial convolution and sums; Q+R bounds all intermediate degrees even before final high-degree cancellation. Form the owner pullback and integer cleared constraints. At every node and group, compute a literal independent SUBSET OF ORIGINAL INTEGER ROWS. The actual existing Python source constructor uses ordinary exact rational forward elimination, retaining normalized pivot rows only as scratch and never as measurement rows. A fraction-free Gaussian/Bareiss implementation is an optional interchangeable replacement, not a description of the current code. Matrices have polynomial-in-p rows and columns. This is finite rank computation, not enumeration of possible bases. Existing source locality, row restoration, degree and actual-row selection identities apply extensionally to this construction.

5. For each t=1,...,Q and group g, enumerate its at most 2^H Boolean words, compute exact integer measurements, and bucket the words by their attained summary. Cache the first representative and the complete word list for each key. The actual code enumerates products of attained measurement keys, a subset of the full summary box of size at most Y; unattained summaries contribute zero. This may store exp(o(n)) words and labels. It does NOT enumerate the Cartesian product of all head-word buckets, which would restore 2^n work.

6. Cache all shifted row coefficient arrays at t and enumerate all support pairs (E,U), U subset E, |E|<=q; there are exactly C pairs. The actual code streams these pairs; materializing them would also fit the stated bound. For each pair and each summary tuple, process head groups separately. Restore the representatives in the OTHER groups; sum over the current group's cached words consistent with E's forced-one condition; evaluate its assigned local factors on the actual corrected port jets; multiply the group sums. Add the Mobius sign (-1)^(|E|-|U|). This is precisely the finite separated-fibre/Boolean-diagonal identity, with materialized rather than streamed loops. All groups' contributions are summed separately then multiplied; there is NO cross-product enumeration of group assignments.

7. Interpolate the Q retained Taylor packets of width J by the exact rational Hermite formula. It returns the integer count of the original graph. Apply the same procedure to the original prefix-restricted tables in at most n+1 calls. The existing count-search correctness selects a full accepted graph assignment when one exists; project its active source digits and validate the proper divisor. Initial count zero certifies no nontrivial factor pair (prime input), as in the actual public factor-count theorem. All local restrictions preserve original arity/incidence. Layout and truth base tables are reusable across prefix calls, though even rebuilding them adds only a polynomial factor.

Correctness of this variant is inherited by finite extensional identities: actual source layout/restoration/locality; exact finite summary fibres with unforced representatives; multilinear Boolean truth interpolation; proved Mobius/Taylor diagonal; exact Hermite reconstruction; public graph factor-count and prefix-search correctness. No desired packet value, rank, count, or representative is an oracle input.

## 3. A non-circular uniform bit-height implementation

Use schoolbook signed integer arithmetic and explicit fixed-denominator INTEGER coefficient arrays, rather than allowing an arbitrary rational expression tree to grow denominators. The following bounds concern EVERY arithmetic prefix, not just the final answer.

Source coefficients have the proved common denominator

    delta = 2^(R-1) * (Q!)^(Q+1),

and integer numerator coefficients bounded by `B*2^rowNumeratorExponent(Q,R)`, B=2 here. The actual definitions in SourceRowHeight make the exponent polynomial in Q,R (and log Q). Taylor shifts multiply coefficient bounds by at most (R+1)*(2(Q+1))^R. Thus all source/shift coefficient bit lengths are bounded by a fixed polynomial in p. No numerical exponent for that polynomial is pinned here.

For row construction itself: binomial/Pascal entries, 2^s targets (s<=R), subset-swap terms and interpolation factors have polynomial-in-p bit length. Polynomial products have at most Q+R factors/degree and add logarithmically many summands; their partial products and convolution sums have polynomial bit length before cancellation. Conditional-expectation comparisons have denominator dividing a fixed product of epsilon-denominator powers and A^4; a term has at most four unresolved labels. Summing its polynomially many terms adds O(log p) bits. No iterated squaring or exponential-depth rational substitution occurs.

For actual measurement basis selection, the existing `select_actual_rows` rational algorithm reduces each new ORIGINAL row against the prior normalized echelon rows, tests its first nonzero entry, and retains the literal original row ID. The normalized echelon entries and every elimination prefix are ratios of minors of the corresponding original augmented row/pivot-column submatrix: solve the previous pivot-coordinate equations by Cramer's rule, then substitute in the remaining coordinate; normalization adds one pivot minor ratio. The same argument applies to the small Gauss-Jordan binomial solve. Hadamard bounds an s-by-s minor by s^(s/2) W^s. Thus all reduced scratch numerator/denominator bit lengths are polynomial in matrix dimensions and log W; unreduced Fraction product/add temporaries add these bit lengths and reduction cannot increase them. Matrix dimensions and log W are polynomial in p. This is a specific Gaussian-elimination invariant, not an inference that arbitrary rational straight-line programs have short intermediates. Optional Bareiss elimination obtains the same row-rank decision with literal minors and exact divisions; it is not required to change the actual code.

For counter packets, a port is P/delta. Evaluate the Boolean extension with integer arrays: true branch uses P; false branch uses delta-P, with the exact constant array delta. A k-port product has denominator delta^k. Pad prefixes to the fixed local arity if desired by multiplying the numerator by delta^(w-k). A truth-table subtotal uses the SAME denominator delta^w; summing its 2^w terms adds at most w bits. Products over assigned factors use delta^(their incidence count). Across all groups, every full term has denominator delta^M. Pad partial products by delta^(remaining incidence). All fibre, summary and support sums retain this ONE denominator; addition never squares or multiplies it.

A coarse coefficient magnitude bound for any local/group/fibre/support partial sum is obtained by summing absolute values of logical terms: at most C*Y*2^n*2^M terms, times products of at most M corrected port coefficients, times at most J^(F+M) convolution choices, times delta^M for padding. Its LOGARITHM is polynomial in p plus log C+log Y; since C<=3^n and log Y is polynomial in p, it is polynomial in p, even though 2^n is used ONLY as a numerical height bound, never a runtime loop. This is exactly the reason the existing PacketHeight/FibreAccumulatorHeight/LocalPrefixHeight fixed-denominator approach is useful. These displayed product/sum bounds give an explicit integer envelope; taking its binary logarithm bounds every stored numerator and denominator. Twice that width plus O(1) bounds raw pre-add/pre-multiply temporaries.

Hermite: let dL=(Q!)^(QJ). Each local cardinal denominator has constant 1 and coefficients represented over dL, with absolute coefficients <=2^(QJ). The explicit inverse recurrence b_k=-sum_(i=1..k)a_i*b_(k-i), b0=1, has denominator dividing dL^k. A uniform denominator dL^J pads ALL cached inverse coefficients and dot-prefixes. The packet times inverse and evaluation at -t use common denominator dH*dL^J, dH=delta^M; the extra scalar cardinal at zero has denominator dividing dL. Consequently all node sums have the SAME common denominator dH*dL^(J+1), not a product over Q nodes. Numerator log bounds grow only polynomially in Q,J,M,log delta and packet-height. Existing HermiteArrayHeight `hermiteDenominator`, quotient-prefix, evaluation-prefix and node-prefix theorems certify precisely this structure. No cancellation-dependent small final answer is used to bound an intermediate.

Let Bbit be twice the maximum of the logarithms of the displayed source-minor, corrected-packet, padded partial-sum, Hermite inverse and node-prefix envelopes, plus the index width log(S+1) and a constant. These are explicit constructor-derived integers, not desired-answer heights. Every term has logarithm polynomial in p, so Bbit=poly(p). Schoolbook multiply/divide/gcd/comparison costs O((Bbit+1)^3) bit steps. All scalar divisions are by explicitly tested nonzero Gaussian pivots or known nonzero interpolation differences; optional Bareiss divisions are exact.

## 4. Explicit conservative total time and memory

One concrete phase ledger (unit-cost bounded-integer scalar operations before the common bit bound) is:

* Conditional source search: O((n+F) A^5 (M^2+Qn^2)) local score-term calls, with an additional polynomial(Q,n+F+M) factor for literal index/word scans and arithmetic. This is the pinned support-four bound, not a global-label search.
* Universal numerator tables: at most Qr D^2 3^Q entry/subset contributions, each involving polynomial(Q+R) work. Source interpolation and pullback have polynomial(Q,R,M,n,D) coefficient operations.
* Literal basis selection: at most Qr elimination problems, each with at most polynomial(M,D) rows and n columns, hence polynomial(Q,r,M,D,n) exact Gaussian field operations, each with the minor-bound bit sizes above (or the corresponding Bareiss operations in the optional variant). Using the tighter padded-row count <=2M only improves this.
* Head-word measurement caches: O(Qr 2^H poly(n,M)) arithmetic/record work, including grouping by exact integer measurement keys. Sorting may be replaced by quadratic scans of the cached word list; that squares 2^H but remains a fixed polynomial in S.
* Truth tables: at most F 2^w calls of the actual poly(L) Boolean entry checker, plus polynomial storage/index work.
* One counter: at most Q C Y r 2^H F 2^w local truth-product visits. Each visit uses polynomial(n,M,J,w) coefficient work: corrected bases use at most n scalar terms per port, each retained convolution uses at most J^2 products, and local truth interpolation has w ports per Boolean word. Support/summary indexing and forced-one checks use polynomial(n,M) work. Hermite uses O(Q^2 J^3) coefficient operations with cached inverse prefixes.
* Recovery: at most n+1 such counts, followed by polynomial(L) validation and source-word projection. Rebuilding any polynomial-in-p preprocessing per call remains harmless.

Each phase is therefore a fixed polynomial in the EXPLICIT dimensions p,C,Y,2^H,2^w, not exponential in one of those dimensions. Let T be the sum of these displayed phase bounds after choosing straightforward finite-scan implementations of their polynomial factors. Then T=S^O(1). The exponent is a fixed absolute implementation constant; its exact numerical value is NOT pinned by this report. No particular numerical exponent is asserted.

Materialize at most T records of at most polynomial(Bbit,p) bits each. Perform each operation with schoolbook integer arithmetic. If random access is disallowed, implement every read/update by a scan of the entire materialized tape. This multiplies runtime by at most its total bit length, itself polynomial(T,Bbit,p). Thus ordinary deterministic bit/Turing time and space are both polynomial(T,Bbit,p)=S^O(1), with no polynomial-space requirement and no unit-cost unbounded integer operation. This simulation argument needs only finite records and explicit loops; it does not import a runtime claim about Lean evaluation.

Because log S=o(n), Bbit=poly(p), and n=Theta(L), this gives 2^o(L)=N^o(1) paper bit time. In particular it is eventually O(N^(1/12)), leaving room below N^(1/6). Finite rejected guard lengths are handled by the trial-division branch; its asymptotic constant may be enormous. This is a paper algorithm/time result, NOT a newly compiled end-to-end Lean clock theorem.

## 5. Actual executable instantiation and conclusion

`paid_integer_counter.py` is the concrete materialized implementation examined here. `factor(N)` loads the frozen original graph compiler and exact source-layout constructor, checks scope coverage and the actual scheduled guard before allocating the source, constructs the layout once, then invokes the new counter from the old same-scope false-first recovery. No optional cap or silent no-result branch is present. `count` materializes the original Boolean truth tables, every acquired source coefficient, and each head's complete Boolean assignment-to-measurement buckets. Its Cartesian `product` ranges over ATTAINED measurement KEYS only, so it has at most Y tuples, not 2^n assignments.

The source denominator in the code is the actual finite LCM of acquired reduced coefficient denominators. Every such denominator divides the proved source delta, hence every intermediate LCM and the final denominator divide delta. It is not an unbounded LCM of unrelated rational truth callbacks (truth entries are required to be 0 or 1). The homogeneous Jet carries a declared denominator degree: scalar constants start at degree0, each port at degree1, tensor interpolation increments exactly once per port, and the whole factor product reaches M. Addition requires identical declared degree, so fibre/support accumulation cannot drift to a growing denominator. Source coefficients are scaled once to integer arrays; packet results are converted to rational arrays only for the final polynomial-size Hermite call.

The implemented local tensor uses iterative cached paired elimination of Boolean table indices, not a hidden call to a supplied interpolation answer. It enumerates 2^w entries and O(w2^w) polynomial-precision work at worst. The nonempty fibre representative is the first cached word and is unforced; forced-one membership filters only the summation words. This agrees with the proved separated-fibre formula. Wrong or empty summaries are simply absent, and no unique-hit promise is used.

The accompanying seven tests are finite structural/correctness diagnostics, not the asymptotic proof. The time proof above applies to the actual bounded loops and exact integer/Fraction operations of this implementation. Source preprocessing uses its actual rational Gaussian variant and the minor-height argument, not an unimplemented Bareiss assumption. The original prefix recovery count calls remain within the same graph scopes. Actual recorded operation counters are diagnostics only; the bit-time conclusion comes from the finite loop ledger and the common-denominator/minor bounds.

Consequently the explicit uncapped algorithm has deterministic paper bit time N^o(1) on the actual public semiprime family (and exact prime/square handling), subject to the already proved actual source schedule, counter correctness and public graph identities. This is a substantive paper algorithm/result, not merely a new oracle specification. It does NOT certify its entire Python implementation, memory allocator or compiler as a single Lean primitive-machine clock theorem. That formal refinement remains open, but no selected-query acquisition or additional mathematical cancellation is required for this time-only route.

Materialization removes the need to fit source production, support enumeration, representative scans and generic dictionary updates into the original SAT polynomial-space parser/frame machine. A simpler new verified finite-list controller could reuse the existing pure counter identities, while paying polynomial overhead in total subexponential storage. The original OAI machine bridge remains an alternative implementation/formalization route rather than a mathematical prerequisite for this result.

The finite-ring alternative needs a matching source-row construction over distinct residue-field lifts with unit differences and a paid irreducible search; rational sample nodes 1..Q must NOT simply be reduced mod3. The exact rational implementation avoids that separate mismatch.
